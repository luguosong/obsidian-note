答题（quiz）后怎么交互

答错 / 蒙对 → 先看即时解析，再按"还剩什么"决定要不要反馈给老师：

解析看完的状态你的动作
完全懂了，且不是蒙的自己消化、往前走（不必反馈）
还是不懂"为什么"反馈：知识卡点 → 老师换角度 / 更深讲
答案是蒙对的说一声 → 存储强度弱的信号，老师再给一题巩固
同类反复错反馈 → 老师据此调 ZPD、决定回炉还是前进
觉得题 / 解析有问题（歧义 / 讲错）反馈 → 回炉修课

原理：看懂解析 ≠ 记住（那只是 fluency 流畅强度；storage strength 存储强度要靠间隔重来 + 再检索）；你的答题表现还是老师算 ZPD 的输入——quiz 只是兜底，真卡点交给老师。

三种"改法"的心智模型

  • lessons ＝ 教学事件：累加为主，可被老师回炉重修。
  • reference · glossary · MISSION ＝ 活的真相：永远原地改，保持唯一最新版。
  • learning-records ＝ 只增不改的账本：旧的不删，被推翻标 superseded by LR-NNNN。

最佳实践清单

  • 先把 MISSION 说成"能观察到的现实目标"，别停在"想理解 X"。
  • 一次只吃一小口——每课单一收获，守在工作记忆内。
  • 反馈回路拉到最紧：不懂立刻问，练完立刻自评。
  • 诚实暴露水平（会什么、卡哪里），喂准 ZPD。
  • 回看用 reference/，不用 lessons/。
  • 盯 storage strength：间隔重来、检索练习，别信"当场看懂"。
  • 智慧类判断去社区/newsletter 验证。
  • 偏好一次性落 NOTES.md，之后每课自动遵循。
  • 一个目录一个 mission；学不相关的东西另开工作区。
