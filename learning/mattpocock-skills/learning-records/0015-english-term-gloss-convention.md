# 固化「英文术语加中文括号注解」写作约定

2026-07-21 用户要求：课文里 `mission`（使命）、`ZPD`（最近发展区）、`RESOURCES.md`（资源清单）这类英文术语/文件名/缩写，**首次出现**时后加中文括号注解，降低阅读压力；固化为习惯、后续新课照做。已写入 `NOTES.md`「写课注意」+ `lesson-template.html` 顶部硬规则。

**约定要点：**
- **首次出现**加注，同课复现不重复（避免啰嗦）。
- 已在 `GLOSSARY.md`（术语表）的词，注解**用 GLOSSARY 的中文名**保持一致。
- skill 专有名（如 `triage`）首次出现给一句定位注解。

**Implications：**
- 现有 4 课是否回填由用户定（另议）；本约定对后续新课强制生效。
