# 新增「控制边界（硬契约 / 软目标 / 留白）+ 三问定层法」框架（lesson 5）

2026-07-23 用户从"teach 不控制课程网页风格？"的追问，升华出一个可迁移元技能：读任何 skill 先把其要求劈成 **硬契约**（锁死，如文件模型 / 命名 / 账本规矩，不照做就破坏运作）、**软目标**（只给形容词如 beautiful / 一致）、**留白**（压根不管，如具体视觉风格），并用"三问"定层（破坏运作？→硬 / 只给形容词？→软 / 没提？→留白）。已交付 `lessons/0005-read-skill-boundaries.html`、登记 `nav.js`、增补 `GLOSSARY.md`「控制边界」条。

**Implications：**
- 用户已具备"读 skill 边界"的方法，后续深挖新 skill（triage / wayfinder …）可直接调用三问法划其三层，不必重讲。
- 易混点已在课内澄清：本框架的「三层控制边界」≠ 第 3 课的「三层改法模型」——前者＝skill 管多紧，后者＝工作区文件怎么改。
