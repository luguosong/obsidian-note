# 澄清「社区」与「RESOURCES.md」的关系：交流对象是真人场所，不是清单

2026-07-23 用户读第 3 课时识破一处表述谬误：我把第二个交流对象写成「社区＝RESOURCES.md 的 Wisdom」，用户正确反问「文档怎么交流」。已回炉修准——**社区＝有真人的真实场所（GitHub Discussions / Discord / 线下班）才是交流对象；`RESOURCES.md` 的 Wisdom 区只是记录社区门牌号的「通讯录」，本身不是交流对象**。同步修 `lessons/0003-teach-skill.html` 与参考卡 `reference/teach-learner-manual.html`，并把过时的「Wisdom 还是 Gap」更新为「已补 3 个社区」。

**Implications：**
- 用户已牢固区分「资源清单（索引）」与「它指向的真实社区」，未来不必再教这个区别。
- 写课警惕「把 X 和记录 X 位置的清单画等号」这类压缩谬误（如别把 issue 与 issue tracker 文档、术语与 GLOSSARY 画等号）。
