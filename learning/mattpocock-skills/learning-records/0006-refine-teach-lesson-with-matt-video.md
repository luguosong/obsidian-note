# 用 Matt 本人的 teach 介绍视频回炉第 4 课（一手源升级）

2026-07-21 用户贴来 Matt Pocock 亲讲的 teach 介绍视频（YouTube `s5T5oQJcJ6U`，含时间戳转录），要求据此优化课程。据一手源对第 4 课做**外科式增强**：① 增补 **stateful vs stateless** 轴（teach 必须有状态；对照 `grill-me`/`grill-with-docs`）；② 补 **"不要把你钩在 agent 上，是要把你送去社区"** 的设计意图（Matt 9:17–9:51），深化「两个交流对象」里 Wisdom 一端——老师是**脚手架不是终点**；③ 补**跨会话续的 resume 仪式**（报近况→读状态→诊断→现做一课），直接答"怎么用"；④ 反馈回路最佳实践收紧为**"测验只是兜底、要更富的回路"**；⑤ 新增「何时用 teach」（onboarding 代码库 / 个人自学）；⑥ `RESOURCES.md` 把视频列为 teach 专题最高优先"看"一手源，并用视频描述里的**真实 Discord 邀请链接**（`aihero.dev/s/PhJrND`）消掉先前"待核实"旗标。`GLOSSARY.md` 增 `stateful / stateless` 词条。

**Implications：**
- 一手源等级更新：teach 专题"看"类首选＝作者视频；后续讲 teach 相关一律先引它。
- Wisdom 端定性明确：teach 的**终点是把学习者送进社区**，不是长期依赖 agent——后续课的 followup 都应体现"练到位就去 Discussions / 社区验证"。
