# Claude Code Resources

## Knowledge

- [Official Docs: Claude Code Overview](https://docs.anthropic.com/en/docs/claude-code/overview)
  官方文档入口，最权威的参考源。用于：所有功能的事实性查证。

- [Sub-agents](https://docs.anthropic.com/en/docs/claude-code/sub-agents)
  Agent 并行模式详解。用于：理解 Task 工具调度机制、并行任务设计。

- [Hooks](https://docs.anthropic.com/en/docs/claude-code/hooks)
  生命周期钩子完整文档。用于：PreToolCall/PostToolCall 拦截、stdin/stdout JSON 通信协议。

- [Custom Slash Commands](https://docs.anthropic.com/en/docs/claude-code/slash-commands)
  自定义命令文档。用于：命令文件格式、$ARGUMENTS 占位符、命名空间规则。

- [Memory (CLAUDE.md)](https://docs.anthropic.com/en/docs/claude-code/memory)
  记忆层级文档。用于：全局/项目/子目录 CLAUDE.md 的加载顺序与内容设计。

- [MCP Integration](https://docs.anthropic.com/en/docs/claude-code/mcp)
  Model Context Protocol 集成文档。用于：MCP 服务器配置、stdio/SSE transport、CLI 命令。

- [Settings & Permissions](https://docs.anthropic.com/en/docs/claude-code/settings)
  配置文件与权限规则文档。用于：settings.json 结构、allow/deny 规则语法。

- [GitHub Actions Integration](https://docs.anthropic.com/en/docs/claude-code/github-actions)
  CI/CD 集成。用于：Headless 模式与自动化管道。
