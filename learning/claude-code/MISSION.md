# Mission: 系统性掌握 Claude Code

## Why
从安装和基本配置出发，系统性地学习 Claude Code 的全部能力——从日常使用到高级工作流自动化，建立完整的知识体系，消除盲区，最大化日常开发产出。

## Success looks like
- 能独立安装、配置 Claude Code，理解各类配置文件的作用
- 能设计合理的 CLAUDE.md 层级结构，让 Claude 在不同上下文中具备正确的系统级知识
- 能为项目和个人创建可复用的 Slash Commands
- 能合理配置权限规则（allow/deny），理解安全边界
- 能设计并使用 Sub-agent 并行处理复杂任务
- 能配置 Hooks 实现自动化（自动 lint、审计日志、安全护栏等）
- 能集成 MCP 服务器，将外部工具/数据库接入工作流
- 能用 Headless 模式将 Claude Code 嵌入 CI/CD 管道

## Constraints
- 深入浅出，从头系统学习，不跳过基础
- 以官方文档 https://docs.anthropic.com/en/docs/claude-code/ 为主要知识来源

## Out of scope
- Amazon Bedrock / Vertex AI 企业集成（当前不需要）
