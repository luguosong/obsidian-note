Claude Code 系统课 · 第 1 课

安装与基本配置

Claude Code 是 Anthropic 出品的命令行 AI 编程工具，在终端里直接与 Claude 对话、读写代码、执行命令。 这节课完成从零到可用的全部配置，理解 .claude/（配置目录）的目录结构和核心文件的职责——这是后续一切配置的地基。

一句话收获：装好 Claude Code，理解 .claude/ 目录里每个文件的职责，知道配置在哪里改。

1. 前提条件

项目要求检查命令
Node.jsv18 或以上node --version
npm随 Node.js 附带npm --version
Anthropic API Key从 console.anthropic.com 获取—

已有账号直接用

如果你通过 Claude.ai Pro 订阅使用，也可以用 claude login 走 OAuth 授权，不需要手动配置 API key。

2. 安装

方式 A：Windows 官方安装脚本（推荐，无需手动装 Node）

在 PowerShell 中运行：

irm https://claude.ai/install.ps1 | iex

脚本自动处理依赖，安装完成后即可使用 claude 命令。

方式 B：通过包管理器（需已有 Node.js v18+）

包管理器命令
npmnpm install -g @anthropic-ai/claude-code
pnpmpnpm add -g @anthropic-ai/claude-code
yarnyarn global add @anthropic-ai/claude-code

方式 C：macOS / Linux（Homebrew）

brew install claude

方式 D：免安装临时体验

npx @anthropic-ai/claude-code

安装完成后验证：

claude --version

如果输出版本号（如 1.x.x），安装成功。

3. 首次配置：设置 API Key

有两种方式提供 API Key：

方式 A：环境变量（推荐）

# 添加到你的 shell 配置文件（~/.zshrc 或 ~/.bashrc）
export ANTHROPIC_API_KEY="sk-ant-..."

# 重新加载
source ~/.zshrc

方式 B：交互式登录

claude login

根据提示选择 API Key 或 OAuth 方式。

验证配置

# 在任意目录启动 Claude Code
claude

# 发送一条测试消息
> 你好，简单介绍一下你自己

退出交互模式

输入 /exit 或按 Ctrl+C 退出。

4. 核心目录结构

Claude Code 使用两类配置目录，理解它们的作用域是后续一切配置的基础：

目录/文件作用域是否提交 Git职责
~/.claude/全局（所有项目）—你的个人配置，跨项目生效
~/.claude/settings.json全局—个人全局配置（模型、MCP、hooks 等）
~/.claude/CLAUDE.md全局—个人全局系统指令（每个会话都读）
~/.claude/commands/全局—个人自定义 slash commands
.claude/项目级（当前 repo）✅ 建议提交团队共享的项目级配置
.claude/settings.json项目✅项目级配置（权限、MCP、hooks 等）
.claude/settings.local.json项目本地❌ gitignore本地私有覆盖（不提交）
.claude/commands/项目✅团队共享 slash commands
CLAUDE.md项目根✅ 建议提交项目级系统指令

配置优先级（高 → 低）

.claude/settings.local.json   ← 最高优先级（本地覆盖）
.claude/settings.json          ← 项目共享配置
~/.claude/settings.json        ← 用户全局配置（最低优先级）

两条最重要的原则

1. 提交 .claude/settings.json：让团队成员使用一致的项目配置（权限规则、MCP 服务器等）。
2. gitignore *.local.json：本地私有配置（个人 API key helper、本地路径等）永远不提交。

5. 常用启动方式

# 交互模式（最常用）
claude

# 一次性执行任务（不进入交互模式）
claude -p "帮我分析这个项目的代码结构"

# 在指定目录启动
claude --cwd /path/to/project

# 继续上一次会话
claude --continue

# 查看所有可用选项
claude --help
