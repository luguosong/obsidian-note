L1 · 五大单元与冯诺依曼架构

  • 五大单元：输入、输出、控制单元(CU)、算术逻辑单元(ALU)、主存；CU+ALU 合封在 CPU。
  • 数据流：输入 → 主存 → CPU → 主存 → 输出（一切经主存）。
  • 冯诺依曼 / 存储程序：程序也是数据，和数据同住一块内存 → 不改硬件即可换程序。
  • 指令周期：取指(fetch) → 解码(decode) → 执行(execute) → 写回(writeback)，每秒数十亿次。PC 记下条地址、IR 存当前指令。
  • 冯诺依曼瓶颈：CPU↔内存共用一条总线、内存慢 → CPU 常等 → 缓存/多核来缓解。

L2 · CPU：ISA / RISC·CISC / 版图

  • ISA（契约）vs 微架构（实现）：同一 ISA（x86-64）可有多种芯片（Intel Core / AMD Zen）。编译器面向 ISA。
  • RISC/CISC 现代真相：界线已模糊——x86（CISC）内部解码成类 RISC 的微操作 μops；ARM 也早加满指令。差别在功耗/生态，非速度。
  • 版图（2025）：x86-64（桌面/服务器）、ARM（手机→Apple Silicon→Graviton→Windows on ARM，能效王）、RISC-V（开放）。
  • 位数=一次处理/寻址宽度（32 位→4GB）；主频同款才可比；Dennard scaling 终结→功耗墙→多核 + SMT。

  • 局部性（缓存为何有效）：时间（刚用的会再用）+ 空间（邻近会被用）；缓存行 64B 押注空间局部性。

L4 · 数据表示

  • bit / byte：1 byte = 8 bit = 256 种；硬件用二进制（两态最稳）。
  • 十六进制：1 hex 位 = 4 bit（nibble）；两 hex 位 = 一字节（0x00–0xFF）。
  • KiB vs KB：KiB=1024（IEC，系统用）、KB=1000（SI，硬盘/速度用）→「1TB 显示 931GiB」。
  • 编码：ASCII（1B，只够英文）→ Unicode 码点（中=U+4E2D）→ UTF-8（变长 1–4B、兼容 ASCII，全网 99%）。A=1B、中=3B(E4 B8 AD)、emoji=4B。

L5 · 从硬件到操作系统

  • 机器码=CPU 直接跑的位；编译器（C/Rust/Go，一次翻）/ 解释器（Python/JS，逐句）/ 字节码+VM（Java/JVM）。
  • 为什么要 OS：硬件太杂 + 多程序抢资源 + 无保护 → 需统一管理层。
  • 内核四大职责：进程管理、内存管理（虚拟内存）、文件系统、设备驱动。
  • 系统调用（open/read/write/fork）：程序不能直接碰硬件，经系统调用请求内核；用户态↔内核态是 CPU 硬件级保护圈。

L6 · Unix 的诞生与哲学

  • 1969 Thompson（PDP-7，汇编）造原型；1973 Ritchie 用 C 重写 → 可移植（历史转折）。
  • Unix 哲学：一切皆文件 + 每个程序只做一件事 + 用管道组合、处理文本流（ls | grep | wc）。
  • 两大纯种分支：BSD（1977，→ macOS 内核）、System V（1979，AT&T）。

L7 · GNU / GPL / Linux 诞生

  • Stallman：1983 GNU（GNU's Not Unix）、1985 FSF；自由≠免费（free speech, not beer）；四种自由。
  • GPL / copyleft：用了 GPL 代码，衍生也必须 GPL（传染式自由）；Linux 用 GPLv2。开源(OSI,1998) vs 宽松许可(MIT/BSD)。
  • Torvalds 1991：用 GNU 的 gcc/bash 写内核；因 FTP 目录得名 Linux 0.02；遵循 POSIX。
  • 合体 = GNU/Linux：GNU（工具缺内核）+ Linux（内核缺工具）；虚拟团队；Git（2005，也是 Torvalds 写的）。

L8 · 内核 vs 发行版

  • 发行版 = 内核 + GNU 工具 + 软件 + 包管理 + 安装器。内核版本 ≠ 发行版版本。
  • 内核版本号：3.0 起废奇偶、改时间制；LTS ~6 年；现 6.x–7.x（鸟哥停在 4.0）。
  • 两大家族：RPM 系（dnf：RHEL/Fedora/Rocky/openSUSE）、DPKG 系（apt：Debian/Ubuntu）；独立（Arch/Gentoo）。
  • CentOS 死：2020 转 Stream、CentOS 7 于 2024-06-30 EOL → 实操换 Rocky/AlmaLinux 或 Ubuntu。
  • 应用：服务器/云、Android、容器(Docker/K8s)、超算 100%。

L9 · 如何学 Linux

  • 七法：动手>读死书、VM 快照、读一手(RTFM)、项目驱动、系统排错、主动回忆+间隔重复、避教程地狱。
  • 排错：读报错 → man/日志 → 精确搜索 → 专业提问(说清 distro/版本/复现) → 记 solution。
  • 资源：TLCL(Shotts)、LFS101、Missing Semester、OverTheWire Bandit、Linux Journey、man7.org、OSTEP/CSAPP、RHCSA/LFCS/LPIC。
