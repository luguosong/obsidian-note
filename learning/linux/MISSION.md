# Mission: Linux — 从计算机底层到操作系统，彻底搞懂 Linux 的运行原理

## Why
我想彻底搞懂「一台 Linux 机器从硬件到操作系统到底怎么运转」——不是会敲命令就行，而是能说清每一层**为什么这样设计**。以鸟哥私房菜 CentOS7 课程为章节主线走一遍，但鸟哥啰嗦、且停在 2016 年的 CentOS7，我要更精炼、并用现代可靠源（OSTEP / CSAPP / Dive Into Systems 等）把过时或过度简化的点纠正过来。纯兴趣驱动，没有考证或上线压力，追求的是「知其所以然」的心智模型。

## Success looks like
- 能从零画出计算机**五大单元**图，并说清冯诺依曼「存储程序」思想：程序和数据同住内存，CPU 靠「取指→解码→执行→写回」循环把它跑起来
- 能解释**操作系统在这套硬件上扮演什么角色**（分配 CPU 时间、管理内存、驱动设备）——为后面理解 Linux 内核铺垫
- 走完鸟哥主线核心章节（计算机概论 → Linux 是什么 → 文件权限与目录 → 文件系统 → BASH → 进程管理 → …），每一章都能讲清**底层原理**而非只记命令
- 遇到鸟哥里**过时的点**（CentOS7 特有、老硬件举例、RISC/CISC 老划分等）能识别，并知道现代正确说法

## Constraints
- 兴趣驱动、节奏自由；每课要**短、单一收获**（teach 规则），不求一次讲完一整章
- 中文授课；命令 / 标识符 / 术语保留原文，英文术语首次出现加中文括号注解
- 以鸟哥 CentOS7 课程为**章节主线**，但知识点以**现代可靠源为准**，过时处必须纠正并注明出处
- 课程形态 = HTML 交互课（`learning/linux/`），复用统一「墨夜」暗色设计系统；**不进** Obsidian 图谱

## Out of scope
- 备考具体认证（RHCSA / LFCS）的应试技巧——不是当前目标
- 特定发行版的安装点按细节（如鸟哥第 3 章 CentOS7 安装截图流程）——原理讲到即可，不逐步复刻过时安装流程
- 桌面美化 / 具体应用软件的使用教程
