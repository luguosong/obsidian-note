内核 vs 发行版：现代版图与 CentOS 之死

上一课我们说清了「Linux 严格讲只是内核」。可你平时装的是 Ubuntu、CentOS——那些是发行版。 这一课分清两者、看懂发行版的两大家族与现代版图，并正面处理一件事：本课主线教材 CentOS 7，已经死了。

这节课的收获：你能分清内核 vs 发行版（发行版 = 内核 + GNU 工具 + 软件 + 包管理 + 安装器）、读懂内核版本号、说出发行版两大家族（RPM 系 / DPKG 系），并知道 CentOS 7 已 EOL、该换 Rocky/AlmaLinux。

1. 内核 vs 发行版：别再说「我的 Linux 是 7.x」

上一课坐实了：Linux 是内核，加上 GNU 工具才是 GNU/Linux。但内核 + 工具还是黑客级的一堆源码，普通人没法从零装（第 5/7 课）。于是社群和公司把它们打包成能「下一步下一步」装好的成品——这就是 发行版（distribution，简称 distro）：

发行版 = Linux 内核 + GNU 工具 + 一堆应用软件 + 包管理器 + 安装器 + 发行商自己的工具。

所以鸟哥特意纠正过一个常见说法：说「我的 Linux 是 7.x」是不准确的——7.x 是发行版（如 CentOS）的版本号，不是内核版本号。正确说法是「我用的是 CentOS 这个发行版，7.x 版」。内核版本和发行版版本，是两套编号。

2. 内核版本号：从奇偶到时间制

内核版本形如 6.6.9：主版本 . 次版本 . 补丁。但规则变过：

  • 2.6 之前（旧规则）：次版本奇数 = 开发版、偶数 = 稳定版（如 2.5 开发、2.6 稳定）。
  • 3.0（2011）起（现规则）：废弃奇偶之分，改时间制——每约 9–10 周发一个次版本，全部都是稳定版；主版本号满了就进位（4→5→6…）。

生产环境要选 LTS（长期支持）内核，维护约 6 年（如 6.1、6.6、6.12）。用 uname -r 就能查当前内核版本。

纠偏鸟哥：内核早不是 4.0 了

鸟哥停在 2015 年的 4.0。如今主线已经走到 6.x～7.x（2026），十年迭代了几代。所以看到老教材里的版本号，心里要有「这是十年前快照」的自觉——这正是本课处处纠偏的原因。

3. 发行版两大家族：RPM 系 vs DPKG 系

发行版有几百个，但主要按包管理器（装/删/更新软件的工具）分成两大家族，外加一撮独立派：

家族包管理代表发行版典型场景
RPM 系rpm / dnf（旧 yum）RHEL、Fedora、Rocky、Alma、openSUSE企业服务器
DPKG 系dpkg / aptDebian、Ubuntu、Mint桌面、云、通用
独立派各异Arch（pacman、滚动更新）、Gentoo（源码编译）折腾 / 学习 / 极客

好消息：它们再不同，也都用 kernel.org 同一个内核、且遵循 FHS（文件系统目录标准）等规范——所以 /etc、/home、/usr 这些目录在哪个发行版里含义都一样（第 6 章会细讲 FHS）。换发行版，命令和目录八成通用，主要差在包管理器和自带工具。

4. CentOS 之死：本课主线教材已经过时

这是全课最重要的一处纠偏。CentOS Linux 曾是把 RHEL（Red Hat 企业版）源码免费重编译出来的社群版——和 RHEL 几乎一模一样却免费，一度是服务器界的宠儿，鸟哥这门课就基于它。但——

时间发生了什么
2020-12红帽宣布终止 CentOS Linux，转向 CentOS Stream（变成 RHEL 的上游测试版，跑在 RHEL 前面，不再是稳定克隆）
2021-12-31CentOS Linux 8 EOL（提前「暴毙」，引发社群哗然）
2024-06-30CentOS Linux 7 EOL —— 本课教材的基线，正式停止支持

社群的反击很快：两个RHEL 免费重编译版顶了上来，作为老 CentOS 的直接替代：

  • Rocky Linux（由 CentOS 联合创始人发起）
  • AlmaLinux（由 CloudLinux 支持的社群项目）

对你意味着什么

跟着这门课学「原理」完全没问题——绝大多数命令、概念、目录结构十年未变，这也正是本课在做的事。但如果你要装机实操，别再装 CentOS 7（已无安全更新）：想要 RHEL 血统就选 Rocky / AlmaLinux，想要更主流通用就选 Ubuntu / Debian。

5. 应用领域：Linux 到底在哪

第 7 课说「开源无处不在」，这里具体化——也补上鸟哥 2015 版没有的大领域：

领域Linux 的存在感
服务器 / 云几乎整个互联网、AWS/Azure/GCP 的绝大多数实例
手机Android 用 Linux 内核，30 亿+ 设备
容器 / 云原生 🆕Docker / Kubernetes 的基石——2015 后爆发，鸟哥没赶上
超算Top500 超级计算机100% 跑 Linux
嵌入式 / IoT路由器、树莓派、车机、智能家居
桌面份额小，但开发者 / 极客的主力之一

收束：你手里的安卓手机、你打开的每个网站背后的服务器、你以后要跑的每个 Docker 容器——底层几乎都是 Linux 内核。你学它，是在学这个时代的基础设施。第 1 章到此，Linux「是什么、从哪来、长什么样」已经清楚了。

进阶挑战：鸟哥这门课基于 CentOS 7，你现在要动手实操，该装什么发行版？为什么？（先想，再展开）

不要再装 CentOS 7——它 2024-06-30 已 EOL，不再有安全更新，装了就是个漏洞靶子。选择取决于目标：①想 100% 贴合鸟哥的 RHEL/CentOS 体验（同样 RPM/dnf、同样目录与命令）→ 装 Rocky Linux 或 AlmaLinux（RHEL 免费重编译，老 CentOS 的直接接班人）；②想更主流、资料最多、桌面/云都友好 → 装 Ubuntu（DPKG 系，apt）。无论哪个，课里学的原理和绝大多数命令都通用——发行版只换了「包装」，内核与 GNU 工具是同一套。这正是「学原理不过时、装机要更新」的道理。
