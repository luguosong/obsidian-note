如何学 Linux：方法与权威资源地图

前八课把「原理」的地基打牢了。但 Linux 是练出来的，不是读出来的。 这一课给你一套面向「深理解」的学习法，加一张经过核验的权威免费资源地图——不局限于鸟哥，尽量给你最好的一手源。

这节课的收获：你能说出一套有效的 Linux 学习法（动手 / 读一手 / 项目驱动 / 系统排错 / 主动回忆），手握一张权威免费资源地图，并有一条从零到深挖内核的可执行路线。

1. 怎么学才有效：七条原则

融合鸟哥 §1.4 的建议、学习科学，和业界实践，浓缩成七条（越靠前越重要）：

  1. 动手 > 读死书

    Linux 是练出来的。装个虚拟机或云主机，天天泡在终端里，导航、改文件、调权限、跑脚本。鸟哥反复强调「实作再实作」。

  2. 安全地「搞坏」

    用 VM 快照：动手前拍个快照，搞崩了一键回滚。沙盒里没有「不敢试」。

  3. 读一手（RTFM）

    任何命令先 man <命令> 或 --help，再查官方文档 / Arch Wiki——一手源永远优于二手博客（这也是本课的信条）。

  4. 项目驱动

    带着真问题学：搭个文件/网站服务器、写个备份脚本。项目会逼出书上不讲的真坑。

  5. 系统排错

    报错不要跳过——读它、查日志、精确搜索（下一节展开）。真功夫是修错练出来的。

  6. 主动回忆 + 间隔重复

    不是重读，是回想：合上笔记默写命令、隔几天再测（可用 Anki）。本课每课末尾的检索练习，就是在替你做这件事。

  7. 跟结构化路线

    别陷进「教程地狱」（tutorial hell，看一堆入门却从不深入）——沿一条从基础到进阶的主线走（第 4 节给你一条）。

2. 排错的正确姿势

单拎出来，因为它最能体现「深理解」——也是鸟哥那句「学 solution，不是学 answer」的落地（学解决问题的过程，而非死记某个答案）：

  1. 读报错原文

    逐字读——它八成已经告诉你哪儿错了。

  2. 查手册与日志

    man / --help 看用法；去 /var/log/ 看系统怎么说。

  3. 精确搜索

    把报错原句（去掉你机器特有的路径）贴进搜索引擎，优先看官方文档 / Arch Wiki / Stack Exchange。

  4. 提问要专业

    实在卡住再问社区——说清发行版 + 版本 + 复现步骤 + 报错原文，才有人能帮你（回接第 8 课：先讲清是哪个 distro）。

  5. 记录 solution

    把「问题 → 原因 → 解法」记下来，下次秒解，也沉淀成你自己的知识库。

4. 一条可执行的学习路线

结合你「彻底搞懂底层」的目标，给一条从零到深挖的阶梯：

  1. 起步：搭个练习场

    装 VirtualBox + Ubuntu 或 Rocky/Alma（第 8 课；别再装 CentOS 7），或开一台云主机。拍好第一个快照。

  2. 命令行地基

    过一遍 The Linux Command Line，配 OverTheWire Bandit 闯关练手感。

  3. 核心概念

    文件与目录、权限、进程、包管理——跟着鸟哥后续章节 + 本课的纠偏走。

  4. 自动化

    学 Shell 脚本，把重复任务写成脚本（第一个真项目）。

  5. 深挖底层（你的 mission）

    用 OSTEP + CSAPP 追到进程/虚拟内存/文件系统的内核实现；用 strace 亲眼看程序发的系统调用（回接第 5 课）。

  6. 做项目 + 进社区

    配 SSH、搭 Web、写备份、玩 Docker；把理解拿到社区去验证。

5. 收官：这门课本身就是学习法范例

你正在上的这门课，其实一直在示范上面那套方法：

  • 一手源锚定：每课都给权威出处，不信「据说」；
  • 逐处纠偏：鸟哥过时的地方（CentOS、DDR、RISC/CISC…）都用现代源更新；
  • 主动回忆：每课末尾的检索练习，逼你回想而非重读；
  • 压缩沉淀：GLOSSARY 把学过的词压成一句话；
  • 两个交流对象：卡住问老师（我），成熟了去社区真刀真枪验证。
学 Linux，就照这么干：动手、读一手、回想、做项目、进社区。第 1 章到此完整收官——你已经知道 Linux 是什么、从哪来、长什么样、以及怎么学下去了。

5. 鸟哥说「学 solution，不是学 answer」，意思是？

进阶挑战：为什么「做检索练习（主动回忆）」比「把笔记重读一遍」记得更牢？（先想，再展开）

因为记忆靠提取而非重看变强。主动回忆（active recall）：合上资料、从脑子里把答案调出来，这个「费劲提取」的动作会强化神经通路，把知识从「一时想得起」变成「长期记得住」（storage strength）。重读只带来流畅错觉（fluency）——你觉得「我都懂」，一合书却想不起。再叠加间隔重复（隔几天再测、快忘时再捞），效果更好。这正是本课每课都放检索练习、而不是让你重读正文的原因。

推荐一手源

  • The Linux Command Line（William Shotts，免费 PDF） —— 命令行入门到脚本的免费圣经。动手阶段首选精读。
  • Linux Foundation · Introduction to Linux（LFS101，免费） —— 官方系统入门课。
  • OverTheWire · Bandit + man7.org —— 边玩边练 + 最权威手册。
  • 鸟哥 §1.4 —— 学习建议（实作再实作、学 solution 不学 answer、排错流程）。本课在其上补齐了现代资源与学习科学。
