## Awesome DESIGN.md

把某个 DESIGN.md 复制到你的项目里，告诉你的 AI 智能体(agent)「按这个样子给我做一个页面」，就能生成与该设计语言视觉一致的高质量 UI。

它内建真正的设计深度——包含经分析的模式(pattern)、设计令牌(token)与规则——用于生成高质量 UI，而非浮于表面的产出。

## DESIGN.md 是什么？

[DESIGN.md](https://stitch.withgoogle.com/docs/design-md/overview/) 是 Google Stitch 提出的新概念。一份纯文本的设计系统文档，供 AI 智能体读取以生成一致的 UI。

它就是一个 markdown 文件。无需 Figma 导出，无需 JSON 模式(schema)，无需任何专门工具。把它放到项目根目录，任何 AI 编码智能体或 Google Stitch 都能瞬间理解你的 UI 该长什么样。Markdown 是大语言模型(LLM)最擅长读取的格式，因此无需解析、无需配置。

| 文件 | 谁读取它 | 它定义了什么 |
| --- | --- | --- |
| `AGENTS.md` | 编码智能体 | 项目该如何构建 |
| `DESIGN.md` | 设计智能体 | 项目该有怎样的外观与质感 |

**本仓库提供从真实网站提取的、即拿即用的 DESIGN.md 文件**。

### 复古 Web · DESIGN.md 怀旧系列

一个周六系列——从 1990 年代的 Web 中提取的 DESIGN.md 文件。放入一个，告诉你的 AI 智能体去构建一个符合时代特征的复古 UI。

- [**Dell (1996)**](https://getdesign.md/dell-1996/design-md) - 目录时代的企业 Web。字面意义的黑色页面边框，平涂色块的「缎带卡片」，Times Roman 正文上压粗壮的 Helvetica-Black 标题，以及手工裁剪的 GIF 贴纸（NEW! 爆炸标、奖章印章、斜切产品照）。
- [**Nintendo.com (2001)**](https://getdesign.md/nintendo-2001/design-md) - Y2K「主机镀铬」风 Web。拉丝长春花蓝斜切金属面板，带半网点碳灰导航泛着琥珀光，电路板底的首屏字段上叠加描边 Arial-Black 游戏封面字标，以及像素风马里奥欢迎气泡。

## 每份 DESIGN.md 里有什么

每个文件都遵循 [Stitch DESIGN.md 格式](https://stitch.withgoogle.com/docs/design-md/specification/)，并扩展了以下章节：

| # | 章节 | 捕获的内容 |
| --- | --- | --- |
| 1 | 视觉主题与氛围 | 情调、密度、设计哲学 |
| 2 | 配色方案与角色 | 语义化命名 + 十六进制色值 + 功能角色 |
| 3 | 排版规则 | 字体族、完整层级表 |
| 4 | 组件样式 | 按钮、卡片、输入框、导航（含各状态） |
| 5 | 布局原则 | 间距比例、网格、留白哲学 |
| 6 | 深度与高度 | 阴影系统、表面层级 |
| 7 | 宜与忌 | 设计护栏与反模式 |
| 8 | 响应式行为 | 断点、触控目标、折叠策略 |
| 9 | 智能体提示词指南 | 快速配色参考、即用型提示词 |

每个站点包含：

| 文件 | 用途 |
| --- | --- |
| `DESIGN.md` | 设计系统（智能体读取的内容） |
| `preview.html` | 可视化目录，展示色样、字号比例、按钮、卡片 |
| `preview-dark.html` | 同一日录的深色表面版本 |

### 如何使用

1. 将某站点的 `DESIGN.md` 复制到你的项目根目录
2. 让你的 AI 智能体使用它。
