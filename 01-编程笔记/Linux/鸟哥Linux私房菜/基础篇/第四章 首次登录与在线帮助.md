# 第四章 首次登录与在线帮助

> [!info] 关于本章
> 本章以鸟哥《Linux 私房菜 — 基础学习篇》第四章为骨架，已将原基于 CentOS 7（GNOME 3 经典模式、X11）的内容更新至 **Rocky/AlmaLinux 9 / RHEL 9 当前状态**（GNOME 40 系列、**Wayland 默认**、systemd、kernel 5.14），术语统一为大陆通行写法。

Linux 是多用户多任务的操作系统，关机有严格的流程——错误的关机方式可能损坏文件系统。本章介绍首次登录、图形与文本界面的使用、文本模式下的命令操作与在线帮助、简单文本编辑器 nano，以及正确的关机方法。

## 4.1 首次登录系统

### 4.1.1 登录图形界面（GNOME）

完成安装并重启后，进入图形登录界面（display manager，RHEL 9 默认为 GDM）。输入用户名和密码即可进入 **GNOME** 桌面（RHEL 9 默认 GNOME 40 系列）。

> [!warning] 不要直接以 root 登录
> root 权限过大，Linux 下许多操作无法撤销。日常请用**普通账号**登录，需要管理系统时再切换为 root（用 `su -` 或 `sudo`）。这样"手滑"造成的损失也更小。

> [!note] Wayland 取代 X11 成为默认
> RHEL 9 的 GNOME 默认使用 **Wayland** 显示服务器（取代传统的 X11/Xorg）。Wayland 更现代、更安全，但部分旧的截屏、远程桌面、键鼠模拟工具仍需退回 X11（在登录界面齿轮处选 "GNOME on Xorg"）。本章涉及的 tty 切换、文本命令操作与显示服务器无关。

### 4.1.2 GNOME 的基本操作与注销

GNOME 桌面主要组成：

- **顶栏（top bar）**：左侧「活动」（Activities，相当于应用入口与窗口/工作区总览）；中间为时间与日历；右侧是系统状态（输入法、音量、网络、电源、当前账号与设置入口）。
- **桌面与文件管理器**：通过「位置」或 Files（文件管理器）浏览家目录、下载、图片等；点击「其他位置」可查看各文件系统的挂载点。
- **工作区（虚拟桌面）**：GNOME 默认使用动态工作区，可在「活动」总览中切换。

> [!tip] 隐藏文件
> 文件名以小数点 `.` 开头的文件默认不显示（如 `.bashrc`）。在 Files 中开启「显示隐藏文件」即可查看。隐藏并非特殊权限，仅是命名约定。

注销与关机：点击顶栏右侧的系统菜单，选择「注销」「关机」或「重启」。注销只让当前账号退出，并非关机。

### 4.1.3 图形界面与文本终端的切换

Linux 默认提供多个**虚拟终端（tty）**，可同时存在图形与文本会话：

| 快捷键 | 用途 |
|---|---|
| `Ctrl + Alt + F2`~`F6` | 切换到文本终端 tty2~tty6 |
| `Ctrl + Alt + F1`（或 `F2`） | 切换回图形会话 |

> [!note] 现代 tty 约定
> systemd-logind 按需激活 tty。GDM（图形登录）通常占用 tty1，用户登录后图形会话常运行在 tty1 或 tty2，文本登录则在其余 tty 上。具体编号因发行版而异，多按几次 `Ctrl+Alt+F1~F6` 即可找到。

若在文本终端想手动启动图形会话，可用 `startx`（需已安装 X Window；Wayland 会话一般由 GDM 直接启动）。开机默认是否进入图形界面，由 systemd 的默认目标控制：

```bash
# 查看当前默认启动目标
systemctl get-default
# 设置开机默认进入图形界面 / 文本界面
sudo systemctl set-default graphical.target   # 图形
sudo systemctl set-default multi-user.target  # 文本
```

> [!info] 从 run level 到 systemd target
> CentOS 7 起已废除传统 SysV 的「运行等级（run level）」，改用 **systemd** 的 target 单元管理服务依赖。`graphical.target` 对应原来的图形运行级，`multi-user.target` 对应原来的文本多用户运行级，已无 `/etc/inittab`。

### 4.1.4 在文本终端登录 Linux

文本终端的登录画面类似：

```text
Rocky Linux 9.x (Blue Onyx)
Kernel 5.14.0-xxx.el9.x86_64 on an x86_64

study login: dmtsai
Password:                      # 输入密码时屏幕无回显，属正常
Last login: Tue Aug  5 09:12:33 on tty2
[dmtsai@study ~]$ _
```

各项含义：

- 第 1 行：发行版名称与版本（此处以 Rocky Linux 9 为例）。
- 第 2 行：内核版本与硬件架构（x86_64）。
- `study login:`：`study` 是主机名；后面输入账号。
- `Password:`：输入密码，屏幕**不会显示任何字符**，这是安全设计，并非键盘故障。
- `Last login:`：上次登录的时间与终端，建议核对是否为本人操作。
- `[dmtsai@study ~]$`：命令提示符——`dmtsai` 为当前账号，`study` 为主机名，`~` 为当前所在目录（家目录），`$` 为普通用户提示符（root 为 `#`）。

> [!tip] `~` 与提示符
> `~` 代表当前用户的家目录：root 在 `/root`，普通用户 dmtsai 在 `/home/dmtsai`。提示符 root 为 `#`、普通用户为 `$`，可据此判断身份。前两行欢迎信息来自 `/etc/issue`。

注销（退出当前会话，非关机）：

```bash
[dmtsai@study ~]$ exit      # 或按 Ctrl-D
```

## 4.2 文本模式下的命令操作

文本模式登录后获得的命令解释程序称为 **shell**（Linux 默认是 **bash**）。我们通过 shell 输入命令与系统交互。

### 4.2.1 命令的基本语法

```text
[dmtsai@study ~]$ command [-options] parameter1 parameter2 ...
                     命令     选项        参数1        参数2
```

要点：

- 一行命令中**第一个输入的一定是命令**（或可执行文件、脚本）；
- 选项通常以 `-` 开头（短选项如 `-h`），完整名以 `--` 开头（如 `--help`）；个别命令的格式化参数以 `+` 开头（如 `date +%F`）；
- 命令、选项、参数之间用**空格**分隔，无论空几格 shell 都视为一格；
- 按 `Enter` 开始执行；命令太长可用反斜杠 `\` 续行（反斜线后紧跟换行）；
- **Linux 区分大小写**：`cd`、`CD`、`Cd` 是不同的。

示例：

```bash
[dmtsai@study ~]$ ls -al ~      # 列出家目录所有文件（含隐藏文件）
[dmtsai@study ~]$ date          # 显示日期时间
[dmtsai@study ~]$ DATE          # bash: DATE: command not found（大小写不同）
```

**语系（locale）**：若命令输出乱码，多半是终端编码与当前 locale 不匹配。可临时切换为英文：

```bash
[dmtsai@study ~]$ LANG=en_US.UTF-8
[dmtsai@study ~]$ export LC_ALL=en_US.UTF-8
[dmtsai@study ~]$ date
```

> [!note] LANG 与 LC_ALL
> `LANG` 只影响输出消息语言；`LC_ALL` 会覆盖所有 locale 类别。等号两边不能有空格。该设置仅对本次登录有效，注销后失效（持久化写入 `/etc/locale.conf` 或 `~/.bashrc`）。

### 4.2.2 基础命令示例

**`date`——日期时间**

```bash
[dmtsai@study ~]$ date +%Y/%m/%d      # 格式化输出
2026/08/05
[dmtsai@study ~]$ date +%H:%M
09:12
```

**`cal`——日历**

```bash
[dmtsai@study ~]$ cal                 # 本月月历
[dmtsai@study ~]$ cal 2026            # 全年
[dmtsai@study ~]$ cal 10 2026         # 指定年月
[dmtsai@study ~]$ cal 13 2026         # 非法月份，会报错并提示
cal: illegal month value: use 1-12
```

**`bc`——任意精度计算器**

`bc` 进入后是一个交互式环境，用 `quit` 退出。运算符：`+ - * / ^ %`。默认整除，用 `scale=N` 设定小数位数：

```text
[dmtsai@study ~]$ bc
scale=3
1/3
.333
10/100
0
quit
```

> [!note] 两种命令行为
> 命令分两类：一类**直接输出结果并返回提示符**（如 `date`、`cal`、`ls`）；一类**进入该程序的环境**，需用其专属命令退出（如 `bc` 用 `quit`）。看到 `[dmtsai@study ~]$` 提示符即在等待命令输入。

### 4.2.3 重要快捷键：Tab、Ctrl-C、Ctrl-D

**`Tab`——自动补全**（bash 最实用的功能之一）：

| `Tab` 位置 | 作用 |
|---|---|
| 命令的第一个词之后 | **命令补全** |
| 第二个词及之后 | **文件名补全** |
| 选项 `--` 之后（需 `bash-completion`） | **选项/参数补全** |

连按两次 `Tab` 会列出所有匹配项：

```bash
[dmtsai@study ~]$ ca[Tab][Tab]      # 列出所有以 ca 开头的命令
[dmtsai@study ~]$ date --[Tab][Tab] # 列出 date 的所有长选项
```

> [!tip] bash-completion
> RHEL 9 默认安装 `bash-completion`，它在许多命令后提供**选项与参数补全**（如 `date --<Tab><Tab>` 列出选项）。善用 Tab 能大幅减少输入错误。

**`Ctrl-C`——中断当前进程**：当命令"跑不停"时按 `Ctrl-C` 强制中断（向前台进程发送 `SIGINT` 信号）。

**`Ctrl-D`——输入结束（EOF）**：表示键盘输入结束；在空提示符处相当于 `exit`，可直接注销。

**`Shift + Page Up / Page Down`**：在文本终端中上下翻页查看历史输出（图形终端里用鼠标滚轮或 `Shift+滚轮`）。

### 4.2.4 查看错误信息

输错命令时，bash 会给出提示，自 CentOS 7 起还会推荐相似命令：

```text
[dmtsai@study ~]$ DATE
bash: DATE: command not found...
Similar command is: 'date'
```

出现 `command not found` 的常见原因：软件未安装；该命令所在目录不在 `PATH` 中；或纯粹打错了字。

## 4.3 Linux 的在线帮助：man page 与 info page

Linux 命令数量庞大（仅以 `g` 开头就有两百余条），无需死记。开源软件通常自带详尽的在线文档。

### 4.3.1 命令的 --help 选项

绝大多数命令支持 `--help`，可快速列出语法与常用选项：

```bash
[dmtsai@study ~]$ date --help
Usage: date [OPTION]... [+FORMAT]
  or:  date [-u|--utc|--universal] [MMDDhhmm[[CC]YY][.ss]]
...
  -d, --date=STRING         display time described by STRING, not 'now'
...
```

`--help` 适合回忆**已用过命令**的选项；若要查**没用过的命令**或**文件格式**，则需要 man page。

### 4.3.2 man page

`man` 是 manual（手册）的缩写，是 Linux 最主要的在线帮助工具：

```bash
[dmtsai@study ~]$ man date
```

man page 第一行形如 `DATE(1)`，括号内的数字表示该条目的**章节号**，含义如下：

| 代号 | 代表内容 |
|---|---|
| 1 | 用户在 shell 中可执行的命令或可执行文件 |
| 2 | 系统调用（内核可调用的函数） |
| 3 | 常用的库函数（多为 C 库 libc） |
| 4 | 设备文件说明（通常在 `/dev` 下） |
| 5 | 配置文件或某些文件的格式 |
| 6 | 游戏 |
| 7 | 惯例与协议（如文件系统、网络协议、ASCII 码等说明） |
| 8 | 系统管理员可用的管理命令 |
| 9 | 与内核相关的文档 |

> [!tip] 记住 1、5、8
> 其中 **1（用户命令）、5（配置文件格式）、8（管理命令）** 三个章节最常用，建议牢记。

man page 的常见结构：

| 段落 | 说明 |
|---|---|
| NAME | 命令/文件的简短名称与一句话说明 |
| SYNOPSIS | 简要语法 |
| DESCRIPTION | 较完整的说明（重点阅读） |
| OPTIONS | 所有选项的详细说明 |
| FILES | 相关或引用到的文件 |
| EXAMPLES | 示例 |
| SEE ALSO | 可进一步查阅的相关资料 |
| AUTHOR / COPYRIGHT | 作者与版权信息 |

阅读顺序建议：先看 NAME 略知用途 → 通读 DESCRIPTION 掌握细节 → 熟悉的命令直接查 OPTIONS → 最后看 SEE ALSO 与 FILES 扩展。

man page 内常用按键：

| 按键 | 作用 |
|---|---|
| `空格` / `Page Down` | 向下翻一页 |
| `Page Up` / `b` | 向上翻一页 |
| `Home` / `g` | 跳到第一页 |
| `End` / `G` | 跳到最后一页 |
| `/string` | 向下搜索 string |
| `?string` | 向上搜索 string |
| `n` / `N` | 重复搜索 / 反向搜索 |
| `q` | 退出 man page |

**按完整名称查找**（`-f`，等价于 `whatis`）：

```bash
[dmtsai@study ~]$ man -f man
man (1)              - an interface to the on-line reference manuals
man (7)              - macros to format man pages
```

指定章节阅读：`man 1 man` 与 `man 7 man` 内容不同；不带章节号时按搜索顺序取靠前的（通常是小号）。

**按关键字查找**（`-k`，等价于 `apropos`）：

```bash
[dmtsai@study ~]$ man -k man     # 在名称与简介中搜索含 man 的条目
```

> [!note] whatis 数据库
> `whatis`/`apropos` 依赖 whatis 数据库。若查不到结果，以 root 执行 `mandb`（旧版为 `makewhatis`）重建。man page 文件存放在 `/usr/share/man`，搜索路径配置在 `/etc/man_db.conf`。

### 4.3.3 info page

`info` 是 Linux 特有的另一种帮助系统，将一份文档拆成多个**节点（node）**，节点之间类似网页超链接，可逐页跳转——相当于文本模式的超文本文档。

```bash
[dmtsai@study ~]$ info info
```

首行信息含义：`File`（来源文件）、`Node`（当前节点）、`Next`（下一节点）、`Prev`（上一节点）、`Up`（上层节点）。

![[vbird-542e5501b6a91b95.gif]]
*图：info page 各节点的关系示意*

info page 常用按键：

| 按键 | 作用 |
|---|---|
| `空格` / `Page Down` | 向下翻一页 |
| `Page Up` | 向上翻一页 |
| `Tab` | 在节点（`*` 标记）之间跳转 |
| `Enter` | 进入光标所在节点 |
| `n` / `p` / `u` | 下一节点 / 上一节点 / 上层节点 |
| `b` / `e` | 跳到当前节点首 / 末 |
| `s` string | 搜索 |
| `h` / `?` | 帮助 |
| `q` | 退出 |

info 格式文档存放在 `/usr/share/info/`。非 info 格式的文档用 info 打开时，效果与 man 相同。

### 4.3.4 其他文档：/usr/share/doc/

除命令帮助外，许多软件的详细说明、HOWTO、原理文档放在 `/usr/share/doc/` 下，按软件包分目录（如 `/usr/share/doc/nano-*/`）。

> [!tip] 三种帮助的取舍
> - 知道命令、忘了选项 → 先 `--help`；
> - 不熟的命令或要查文件格式 → `man` / `info`；
> - 要部署某项服务或了解一组软件 → `/usr/share/doc/` 与官方文档。

## 4.4 简单文本编辑器：nano

nano 是对新手友好的文本编辑器（功能更强的 vi/vim 在后续章节介绍）：

```bash
[dmtsai@study ~]$ nano text.txt      # 文件不存在则新建，存在则打开
```

界面底部两行是快捷键提示，`^` 表示 `Ctrl`、`M` 表示 `Alt`。常用快捷键：

| 快捷键 | 作用 |
|---|---|
| `Ctrl-G` / `F1` | 查看帮助 |
| `Ctrl-O` | 保存 |
| `Ctrl-X` | 退出（若修改过会询问是否保存） |
| `Ctrl-R` | 读入其他文件内容 |
| `Ctrl-W` | 搜索字符串 |
| `Ctrl-C` | 显示当前光标行列位置 |
| `Ctrl-_` | 跳转到指定行号 |
| `Alt-Y` | 语法高亮开关 |
| `Alt-M` | 启用鼠标移动光标 |

> [!tip] 退出 nano
> `Ctrl-X` 退出；若内容有改动，会询问 `Save modified buffer?`，按 `Y` 保存、`N` 不保存、`Ctrl-C` 取消。保存时确认文件名后按 `Enter` 即可。

## 4.5 正确的关机方法

Linux 是多用户多任务系统，后台常有他人或服务在运行（网页、邮件、文件传输等）。**直接断电会中断这些任务，并可能因数据未及时写回磁盘而损坏文件系统**。关机前应：

- **查看系统使用状态**：`who`（谁在线）、`ss -a`（替代已弃用的 `netstat`，查看网络连接）、`ps aux`（查看进程）；
- **通知在线用户**：用 `shutdown` 的广播消息；
- **使用正确的关机命令**。

> [!warning] 远程关机须 root
> 在主机物理终端（tty）上，部分发行版允许普通用户关机；但**远程 SSH 登录时只有 root**（或具备 sudo 权限）才能执行 `shutdown`、`reboot` 等。

**`sync`——把内存数据写回磁盘**

为提升性能，Linux 把已修改的数据先暂存于内存，延后写入磁盘。关机前执行 `sync` 强制刷盘，防止异常断电丢数据：

```bash
[dmtsai@study ~]$ su -                # 切换为 root（输入 root 密码）
[root@study ~]# sync                  # 多执行几次更稳妥
```

普通用户执行 `sync` 只刷自己的数据，root 则刷整个系统。现代 `shutdown`/`reboot` 已自动调用 `sync`，但关机前手动执行仍是好习惯。

**`shutdown`——推荐的关机命令**

```text
shutdown [-krhc] [时间] [警告消息]
```

| 选项 | 作用 |
|---|---|
| `-k` | 仅发送警告消息，不真的关机 |
| `-r` | 停止服务后**重启** |
| `-h` | 停止服务后**关机** |
| `-c` | 取消正在进行的 shutdown |

时间示例：

```bash
[root@study ~]# shutdown -h now             # 立即关机
[root@study ~]# shutdown -h 20:25           # 今天 20:25 关机
[root@study ~]# shutdown -h +10             # 10 分钟后关机
[root@study ~]# shutdown -r +30 'Reboot in 30 min'   # 30 分钟后重启并广播
[root@study ~]# shutdown -k now 'Test only' # 仅警告，不关机
```

不带时间参数时默认 1 分钟后关机；可用 `shutdown -c` 取消。

**`reboot` / `poweroff` / `halt`**

三者最终都调用 `systemctl`，行为可互换，按习惯选用其一即可：

```bash
[root@study ~]# sync; sync; sync; reboot   # 重启（先多次 sync）
[root@study ~]# poweroff                    # 关机
[root@study ~]# halt                        # 停机（可能不切断电源）
```

**`systemctl`——systemd 的统一入口**

`halt`、`poweroff`、`reboot`、`shutdown` 在底层都是 `systemctl` 的别名。与关机相关的语法：

```bash
systemctl reboot      # 重启
systemctl poweroff    # 关机
systemctl halt        # 停机
systemctl suspend     # 挂起到内存（休眠）
```

> [!info] init 与 run level 已退居兼容
> 老式的 `init 0`（关机）、`init 6`（重启）在 RHEL 9 上仍可用，但只是转发给 systemd，"运行等级"概念已被 target 取代。

## 4.6 重点回顾

- Linux 多用户多任务，关机需走正规流程，建议服务器配 UPS；
- 日常用普通账号登录，需要时再切换 root；
- RHEL 9 GNOME 默认 Wayland；图形与文本终端用 `Ctrl+Alt+F1~F6` 切换；
- systemd 用 target（`graphical.target` / `multi-user.target`）取代了 run level；
- 命令提示符 `$` 为普通用户、`#` 为 root；`~` 代表家目录；注销用 `exit` 或 `Ctrl-D`；
- 命令格式：`command [-options] param...`；Linux **区分大小写**；
- `Tab` 补全（命令 / 文件 / 选项）、`Ctrl-C` 中断、`Ctrl-D` EOF；
- 在线帮助三件套：`--help` 快查选项、`man` 查手册（章节 1/5/8 最常用）、`info` 查超文本文档；`/usr/share/doc/` 存放各软件详细文档；
- 关机：`sync` → `shutdown -h` / `poweroff` / `systemctl poweroff`；重启：`reboot` / `systemctl reboot`。

## 4.7 本章习题

1. 文本终端登录界面（`login:` 之前的那几行）来自哪个文件？如何用 `man` 查出其中 `\r`、`\m` 等转义序列的含义？
   - 提示：内容写在 `/etc/issue`；先 `man issue` 看格式说明，再按其中的指引 `man agetty`，搜索 `escape`。
2. 用 `date` 的格式化输出显示成 `2026/08/05-09:12` 的形式。
   - 答：`date +%Y/%m/%d-%H:%M`
3. 如何知道 2026 年 10 月 1 日是星期几？
   - 答：`cal 10 2026`
4. 在文本模式下有几个终端可用？如何切换？图形界面在哪个 tty？
   - 答：文本终端 tty2~tty6（`Ctrl+Alt+F2~F6`）；图形会话常在 tty1（`Ctrl+Alt+F1`），具体编号因发行版而异。
5. `/VBird` 与 `/vbird` 是同一个文件吗？
   - 答：不是，Linux 区分大小写。
6. `Tab` 键在命令行的第一个词之后与第二个词之后分别起什么作用？
   - 答：第一个词之后为命令补全；其后为文件名补全；装了 `bash-completion` 还可补选项/参数。
7. 如何用按键强制中断正在运行的进程？
   - 答：`Ctrl-C`。
8. man page 条目名后的数字 1、5、8 分别表示什么？
   - 答：1 = 用户命令；5 = 配置文件格式；8 = 管理命令。
9. 命令输出乱码，可能原因是什么？如何临时修正？
   - 答：多半是 locale 问题；`export LANG=en_US.UTF-8` 或 `export LC_ALL=en_US.UTF-8`。
10. `ls -al /vbird` 报 `No such file or directory`，发生了什么？
    - 答：系统中不存在 `/vbird` 这个文件/目录。
11. `$` 与 `#` 提示符有何区别？日常该用哪个？
    - 答：`#` 为 root，`$` 为普通用户；日常用普通用户（`$`），需要时再提权。
