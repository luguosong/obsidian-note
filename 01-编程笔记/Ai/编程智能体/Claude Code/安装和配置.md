# 安装和配置

## 概述

> [!note] 定义
> Claude Code 是一种驻留在 `终端` 中的 `代理式`（agentic）编码工具，它理解你的代码库，并通过执行常规任务帮助你更快地编写代码。

## 安装

```shell
# macOS, Linux, WSL
# 默认会自动更新
curl -fsSL https://claude.ai/install.sh | bash
# 稳定版，通常落后约一周、跳过重大回归版本
curl -fsSL https://claude.ai/install.sh | bash -s stable

# Windows 官方安装脚本（推荐，无需手动装 Node）
irm https://claude.ai/install.ps1 | iex

# npm 安装
# npm 包里没有一行 JS 实现——它只是个约 178 KB、7 个文件的薄壳，
# 真正的原生二进制经 8 个平台可选依赖下发，由 postinstall 脚本链接到位。
# 同样会自动更新
npm install -g @anthropic-ai/claude-code
```

**安装成功验证**

```shell
# 查看当前版本
claude --version

# 安装健康与设置的只读诊断：安装方式识别、settings 校验错误、最近一次更新尝试结果。它不启动会话、不弹信任提示。
claude doctor
```

### 程序真实存放位置

真实的程序放在 `~/.local/share/claude/versions/` 下。

#### 为什么真实程序路径下会有多个版本？

![[Pasted image 20260907180158.png]]
*图为 WSL（Ubuntu）中的 versions 目录*

- **当前会话**：`claude` → `versions/2.1.258`
- **后台下载**：先写入并校验 `versions/2.1.263`
- **下次启动**：软链 `claude` → `versions/2.1.263`

> [!tip] 这样设计的好处
> 更新失败不会破坏正在运行的旧程序，也不会中断当前会话。

## 登录

### 官方登录

- 用户凭证存放位置：`~/.claude/.credentials.json`
- `ANTHROPIC_API_KEY` 优先于 `/login` 的订阅凭证

### 第三方登录

- 配置位置：macOS & Linux 为 `~/.claude/settings.json`，Windows 为 `用户目录/.claude/settings.json`
- 在会话里运行 `/status`：它显示已加载的 setting sources（配置来源）

编辑或新增 `settings.json`，新增或修改其中的 `env` 字段（把 `YOUR_API_KEY` 替换为上一步获取到的 API Key），并新增 `hasCompletedOnboarding` 参数：

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "YOUR_API_KEY",
    "ANTHROPIC_BASE_URL": "https://open.bigmodel.cn/api/anthropic",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "glm-5.3-flash[1m]",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "glm-5.3[1m]",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "glm-5.3[1m]",
    "CLAUDE_CODE_AUTO_COMPACT_WINDOW": "1000000",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": 1,
    "API_TIMEOUT_MS": "3000000"
  }
}
```
