# 安装和配置

## 概述

> [!note] 定义
> Claude Code 是一种驻留在 `终端` 中的 `代理式`（agentic）编码工具，它理解你的代码库，并通过执行常规任务帮助你更快地编写代码。

## 安装

```shell
# macOS, Linux, WSL
# 默认会自动更新
curl -fsSL https://claude.ai/install.sh | bash
# 稳定版，通常落后约一周、跳过重大回归版本
curl -fsSL https://claude.ai/install.sh | bash -s stable

# Windows 官方安装脚本（推荐，无需手动装 Node）
irm https://claude.ai/install.ps1 | iex

# npm 安装
# npm 包里没有一行 JS 实现——它只是个约 178 KB、7 个文件的薄壳，
# 真正的原生二进制经 8 个平台可选依赖下发，由 postinstall 脚本链接到位。
# 同样会自动更新
npm install -g @anthropic-ai/claude-code
```

**安装成功验证**

```shell
# 查看当前版本
claude --version

# 安装健康与设置的只读诊断：安装方式识别、settings 校验错误、最近一次更新尝试结果。它不启动会话、不弹信任提示。
claude doctor
```

### 程序真实存放位置

真实的程序放在 `~/.local/share/claude/versions/` 下。

**为什么真实程序路径下会有多个版本？**

![[Pasted image 20260907180158.png]]
*图为 WSL（Ubuntu）中的 versions 目录*

- **当前会话**：`claude` → `versions/2.1.258`
- **后台下载**：先写入并校验 `versions/2.1.263`
- **下次启动**：软链 `claude` → `versions/2.1.263`

> [!tip] 这样设计的好处
> 更新失败不会破坏正在运行的旧程序，也不会中断当前会话。
