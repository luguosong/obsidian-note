# 安装的软件

## 开发环境版本

当前主力开发环境（截至 2026-07）：

| 环境 | 版本 | 说明 |
|---|---|---|
| JDK | 21.0.11（LTS） | Java 主力版本 |
| Node.js | 24.18（nvm 管理） | 首选包管理器 pnpm 11 |
| Python | 3.14.6 | 脚本与工具链依赖 |
| Rust | 1.97（rustup） | rtk 依赖 |
| PowerShell | 7.6.3 | 主力 shell |
| Docker | 29.6 | 容器化开发 |
| WSL | 2.7（WSL2） | Linux 子系统 |

## 已安装

### 浏览器与网络

- chrome — 主力浏览器，日常上网与前端调试
- clash verge — 网络代理客户端，访问外网资源

### 办公与文档

- wps — 办公套件，处理 Word / Excel / PPT
- Typora — 所见即所得的 Markdown 编辑器
- obsidian — 本地知识库，就是本笔记仓库
- EdrawMind — 思维导图（亿图脑图）
- manggo — [翻译软件](https://manggo.pylogmon.cn/)，划词翻译

### 开发工具

- idea — Java 主力 IDE（IntelliJ IDEA）
- jdk21 — Java 运行时与开发包（LTS）
- Python — 脚本语言运行时，工具链依赖
- nvm — Node 版本管理（当前 Node 24），配合 pnpm 作首选包管理器
- Rustup — Rust 工具链安装器（rtk 依赖）
- git — 版本控制
- gh — GitHub CLI，命令行管理 issue / PR / 仓库
- tortoise svn — SVN 图形客户端，对接老项目
- docker desktop — 容器化开发与部署
- WSL — Windows 下的 Linux 子系统
- Visual Studio 2022 生成工具 — C/C++ 原生编译构建
- Windows SDK — Windows 应用开发包
- navicat — 数据库可视化客户端
- mobaxterm — 集成 SSH / SFTP / 终端，连服务器
- powershell 7 — 现代 shell，比 Windows PowerShell 5.1 好用
- Windows Terminal — 多标签终端，聚合各种 shell
- notepad++ — 轻量文本编辑器，看日志、改配置

### 系统与效率工具

- everything — 文件名秒级搜索
- 7-Zip — 压缩解压
- snipaste — 截图与贴图
- keepass 2 — 本地密码管理
- trafficmonitor — 任务栏显示网速 / CPU / 内存

### 影音与通讯

- 微信 — 即时通讯
- potplayer — 视频播放器，格式支持全
- 百度网盘 — 云存储与下载

### 系统 / OEM（整机自带）

- 联想电脑管家 — 联想官方驱动更新与系统服务
- Legion Zone — Legion 性能模式 / 灯效 / 风扇控制中心
- NVIDIA 图形驱动 — 独显驱动（560.94）
- Tobii Experience — 眼动追踪软件（Legion 机型自带）

## 未安装

- 欧陆词典 — 词典翻译，manggo 已覆盖，备选
- 罗技G HUB — 罗技外设的驱动与配置

## 建议补充（查漏补缺）

> 按 Java + React 全栈开发场景整理，按需取舍。

### 开发相关

- VS Code — 前端 / TypeScript 主力编辑器，配合 React
- Postman 或 Bruno — HTTP 接口调试
- DBeaver — 开源多数据库管理，补 navicat 不足
- scoop — 命令行包管理器，装软件省心

### 通用

- SumatraPDF — 轻量 PDF 阅读器
- ToDesk 或 向日葵 — 远程协助
- uTools — 快捷启动与效率工具箱
