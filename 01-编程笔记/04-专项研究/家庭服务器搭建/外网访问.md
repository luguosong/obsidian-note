# 外网访问

## Cloudflare tunnel 内网穿透

前提：

- 有一个域名


登录Cloudflare，点击添加站点，输入域名：

![[Pasted image 20260722175700.png]]

去域名注册的网站修改Cloudflare提供的名称服务器：

![[Pasted image 20260722180351.png]]

![[Pasted image 20260722180314.png]]


点击进入Zero Trust:

![[Pasted image 20260722180547.png]]


选择 连接器 -> 添加隧道，给隧道起一个名字（这代表你想穿透的机器）：

![[Pasted image 20260722180924.png]]

按网站提示，去对应电脑安装程序，并执行命令（命令行需要以管理员身份启动），安装服务：

![[Pasted image 20260722181058.png]]

配置子域名和服务器对应程序的协议和端口：

![[Pasted image 20260722181826.png]]

后续可以用该隧道暴露更多的程序：

![[Pasted image 20260722182134.png]]
