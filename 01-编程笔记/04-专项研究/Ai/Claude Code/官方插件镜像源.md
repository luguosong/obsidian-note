# 官方插件镜像源

> [!note] 定位
> 本篇是 `claude-plugins-official` **插件市场**的全量清单速查，按 Anthropic 自研 / 第三方收录两大类、再按市场原生 category 分类罗列。不套用四段式框架——作为清单索引，按用途分类更利于检索。其中绝大多数第三方插件是各厂商 [[MCP]] 服务 / [[skills]] 的封装。

> [!important] 仓库 ≠ 市场：258 是市场总数，不是仓库目录数
> `[ anthropics/claude-plugins-official ]`(https://github.com/anthropics/claude-plugins-official) 这个仓库扮演的是**市场目录（marketplace）**角色：
>
> - 它根目录的 `.claude-plugin/marketplace.json` 清单**登记了 258 个插件**——这才是 `/plugin > Discover` 里看到的「可安装插件数」。
> - 但只有 **52 个物理存在于本仓库**：`plugins/` 下 37 个 Anthropic 自研（外加 `example-plugin` 参考模板，不在清单中）+ `external_plugins/` 下 15 个第三方镜像。
> - 其余 **206 个以 `git-subdir` / `url` 方式指向外部厂商仓库**（AWS / Google / SAP / Shopify / Oracle / Adobe / Microsoft …），清单只记录来源 URL（+ path）+ commit sha，代码并不在本仓库里。
>
> 所以：**「仓库 53 个目录」与「市场 258 个可装插件」并不矛盾**，前者是后者的一个子集 + 外部引用。本笔记按市场清单（258）全量整理。

> [!tip] 安装方式
> 任意插件均可 `/plugin install <插件名>@claude-plugins-official`，或在 `/plugin > Discover` 中浏览。市场源已配置在 `~/.claude/plugins/known_marketplaces.json`（source: `github: anthropics/claude-plugins-official`），本地克隆于 `~/.claude/plugins/marketplaces/claude-plugins-official/`。

## ⭐ 强烈建议先装（精选 15）

> [!tip] 选取原则
> 258 个里绝大多数是**特定厂商/生态专用**（AWS / Google / SAP / Shopify / 各类 SaaS…），只在真用那套生态时才有意义。下面 15 个是**通用、跨项目、几乎人人受益**的，并优先选 **Anthropic 自研 / 本地运行**的——不把代码外发到第三方 SaaS（你是自研、私有部署的国密安全产品，代码外发有合规风险）。
>
> 你已装其中 7 个（✅ 标注），再补 8 个即凑齐。

**A. 通用增强（Claude Code 自身能力，本地运行）**

- ⭐ ✅ `superpowers` — 方法论套件：TDD、系统化调试、子 agent 驱动开发、代码审查、skill 编写。杠杆最高。
- ⭐ ✅ `context7` — 实时拉取任意库/框架的**最新版文档与示例**，对抗训练数据过时（Spring Boot 4 / React 19 这类新栈尤其关键）。
- ⭐ ✅ `claude-md-management` — 维护 CLAUDE.md：沉淀会话经验、审计项目记忆。
- ⭐ `claude-code-setup` — 分析代码库后**推荐定制自动化**（hooks/skills/MCP/subagent），新子项目首跑。
- ⭐ `skill-creator` — 编写、优化、跑 eval 评估自定义 skill（你已有多个项目级 skill，配合它打磨）。
- ⭐ ✅ `hookify` — 把「禁止行为」固化成 hook（你的 CLAUDE.md 里已有一堆「禁止…」，正适合 hook 化）。
- ⭐ `session-report` — 生成会话用量 HTML 报告（token/缓存/高成本 prompt）；你在意 context 健康，用它复盘。

**B. 代码质量与安全（适合国密安全产品）**

- ⭐ `code-review` — Anthropic 多智能体 + 置信度评分的 PR 审查，过滤误报（比内置 `/code-review` 更强）。
- ⭐ `security-guidance` — 对**生成代码**做三层安全审查（注入/XSS/SSRF/硬编码密钥…）；做密码学/签章，强烈建议。

**C. 前端 / 浏览器（你做 React 前端 + Web 中间件）**

- ⭐ ✅ `frontend-design` — 产出有辨识度的前端，避免千篇一律 AI 风。
- ⭐ ✅ `playwright` — E2E 浏览器自动化与测试。
- ⭐ ✅ `chrome-devtools-mcp` — 实时控制 Chrome：调试前端、查网络/console、性能 trace。

**D. 代码导航（大型多仓代码库）**

- ⭐ `serena` — 基于 LSP 的**语义代码导航/重构**，本地运行无云；uocs-project 下多个独立子仓，跨仓理解很值。

**E. 语言服务器（匹配你的技术栈）**

- ⭐ `typescript-lsp` — React 19/18 + TS 前端（upda-cloud-client / drawing-saas-client / drawing-pdf-app…）。
- ⭐ `jdtls-lsp` — Java / Spring Cloud 后端（upda-cloud-server，JDK 21）。

> [!warning] 这类**不建议默认装**（代码/数据外发 SaaS，与私有部署合规冲突）
> `coderabbit` / `greptile` / `sourcegraph`（代码外发审查与索引）、各厂商云 MCP（AWS / Google / SAP …，仅当真用那套生态**且认可其数据流向**时再装）。需要时单独评估。

> 其余 200+ 个都是「按需」：用到哪个生态（某种数据库、CI、部署平台、SaaS…）再对照下面分类表装对应的，无需预先全装。

## 数据来源与更新方法

> [!info] 清单会持续增长，以下为本笔记的数据来源与再生成方式

- **权威清单**：本地市场克隆里的 `~/.claude/plugins/marketplaces/claude-plugins-official/.claude-plugin/marketplace.json`，顶层 `plugins[]` 数组即全部可装插件（本笔记整理时为 **258** 条）。
- **市场源**：`~/.claude/plugins/known_marketplaces.json` 记录 `claude-plugins-official → github: anthropics/claude-plugins-official`。`/plugin` 更新市场后会重新拉取该清单。
- **每条字段**：`name` / `description` / `author.name` / `category` / `source`（`./plugins/…`、`./external_plugins/…` 为本地；`{source:'git-subdir', url, path, ref, sha}` 为外部引用）/ `homepage`。
- **再生成清单**（按 category 分组计数）：

  ```bash
  MF=~/.claude/plugins/marketplaces/claude-plugins-official/.claude-plugin/marketplace.json
  python -c "import json;from collections import Counter;d=json.load(open('$MF'));\
  c=Counter(p.get('category') or '(未分类)' for p in d['plugins']);\
  [print(f'{n:3d}  {k}') for k,n in c.most_common()];\
  print('total =',len(d['plugins']))"
  ```
