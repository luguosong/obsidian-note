# awesome-design

主流品牌**设计系统的 DESIGN.md 分析合集**（VoltAgent 维护，约 73 份）。DESIGN.md 是纯文本 markdown 设计规格（视觉氛围、配色角色、排版、组件、布局、阴影、宜忌、响应式、智能体提示词指南）。把某品牌的一份放进项目，告诉 AI「按这个风格做」，就能生成视觉一致的高质量 UI——对应"设计智能体读 DESIGN.md"，正如"编码智能体读 AGENTS.md"。

## 使用

**无斜杠命令**——它是资源合集，不是插件 / skill。用法：

1. 到 [getdesign.md](https://getdesign.md) 选一个品牌的设计系统；
2. 把对应的 `DESIGN.md` 复制到自己项目根目录；
3. 让 AI 按该 DESIGN.md 生成或重做 UI。

每份还配 `preview.html` / `preview-dark.html` 可视化目录。
