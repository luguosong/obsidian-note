# 基础知识

## 字节码解读

> [!note] 定义
> Java 中每个方法执行时，JVM 都会为它分配一块独立的内存空间，其中两块最重要：
> - `局部变量表`：存储方法的局部变量，按槽位编号（`0` 号通常是 `args`）
> - `操作数栈`：存储运算过程中参与运算的数据，遵循后进先出

> [!tip] 查看字节码
> 源码编译成 `.class` 后，用 `javap -c 类名.class` 反编译查看字节码指令。

涉及的核心指令：

| 指令 | 作用 |
|---|---|
| `bipush n` | 将字面量 `n` 压入操作数栈 |
| `istore_N` | 弹出操作数栈顶元素，存入局部变量表 `N` 号槽位 |
| `iload_N` | 将局部变量表 `N` 号槽位的数据复制压入操作数栈 |
| `iinc N, M` | 将局部变量表 `N` 号槽位的数据加 `M`（直接在槽位上操作，不经过操作数栈） |

把赋值、传递、后置自增、前置自增四步放进同一个 `main` 方法，一次性看全这些指令如何操纵栈帧：

```java
public class ReadClassDemo {
    public static void main(String[] args) {
        int i = 10;       // 示例一：变量赋值
        int j = i;        // 示例二：变量传递
        j++;              // 示例三：后置自增
        int k = ++i;      // 示例四：前置自增
    }
}
```

`javap -c ReadClassDemo.class` 输出的 `main` 方法字节码（构造方法各例相同，省略）：

```text
public static void main(java.lang.String[]);
  Code:
     0: bipush 10
     2: istore_1
     3: iload_1
     4: istore_2
     5: iinc 2, 1
     8: iinc 1, 1
    11: iload_1
    12: istore_3
    13: return
```

逐条指令执行后的栈帧状态（局部变量表槽位：`0=args`、`1=i`、`2=j`、`3=k`）：

| 偏移 | 指令 | 操作数栈 | 局部变量表 |
|---|---|---|---|
| 0 | `bipush 10` | `[10]` | `args` |
| 2 | `istore_1` | `[]` | `args, i=10` |
| 3 | `iload_1` | `[10]` | `args, i=10` |
| 4 | `istore_2` | `[]` | `args, i=10, j=10` |
| 5 | `iinc 2, 1` | `[]` | `args, i=10, j=11` |
| 8 | `iinc 1, 1` | `[]` | `args, i=11, j=11` |
| 11 | `iload_1` | `[11]` | `args, i=11, j=11` |
| 12 | `istore_3` | `[]` | `args, i=11, j=11, k=11` |
| 13 | `return` | — | — |

`j++` 与 `int k = ++i` 就在同一份字节码里，差别只在 `iinc` 与 `iload` 的先后：

| | `j++`（偏移 5） | `int k = ++i`（偏移 8-12） |
|---|---|---|
| 关键指令顺序 | `istore_2` → `iinc 2, 1` | `iinc 1, 1` → `iload_1` → `istore_3` |
| 自增时机 | 先赋值后自增（`j` 先得 10，再变 11） | 先自增后取值（`i` 先变 11，`k` 再得 11） |
