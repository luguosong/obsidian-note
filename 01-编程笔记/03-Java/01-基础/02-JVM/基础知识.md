# 基础知识

## 字节码解读

> [!note] 定义
> Java 中每个方法执行时，JVM 都会为它分配一块独立的内存空间，其中两块最重要：
> - `局部变量表`：存储方法的局部变量，按槽位编号（`0` 号通常是 `args`）
> - `操作数栈`：存储运算过程中参与运算的数据，遵循后进先出

> [!tip] 查看字节码
> 源码编译成 `.class` 后，用 `javap -c 类名.class` 反编译查看字节码指令。

涉及的核心指令：

| 指令 | 作用 |
|---|---|
| `bipush n` | 将字面量 `n` 压入操作数栈 |
| `istore_N` | 弹出操作数栈顶元素，存入局部变量表 `N` 号槽位 |
| `iload_N` | 将局部变量表 `N` 号槽位的数据复制压入操作数栈 |
| `iinc N, M` | 将局部变量表 `N` 号槽位的数据加 `M`（直接在槽位上操作，不经过操作数栈） |

下面通过四个最小示例看这些指令如何操纵局部变量表与操作数栈。每个示例给出源码、`javap -c` 输出，以及逐条指令执行后的栈帧状态。

### 变量赋值 i = 10

`ReadClass01`：

```java
public class ReadClass01 {
    public static void main(String[] args) {
        int i = 10;
    }
}
```

`javap -c ReadClass01.class` 输出（含默认构造方法，后续示例只列 `main`）：

```text
public class ReadClass01 {
  public ReadClass01();
    Code:
       0: aload_0
       1: invokespecial #1  // Method java/lang/Object."<init>":()V
       4: return

  public static void main(java.lang.String[]);
    Code:
       0: bipush 10
       2: istore_1
       3: return
}
```

`main` 方法执行过程：

| 偏移 | 指令 | 操作数栈 | 局部变量表 |
|---|---|---|---|
| 0 | `bipush 10` | `[10]` | `args` |
| 2 | `istore_1` | `[]` | `args, i=10` |
| 3 | `return` | — | — |

### 变量传递 j = i

`ReadClass02`：

```java
public class ReadClass02 {
    public static void main(String[] args) {
        int i = 10;
        int j = i;
    }
}
```

`main` 字节码：

```text
0: bipush 10
2: istore_1
3: iload_1
4: istore_2
5: return
```

| 偏移 | 指令 | 操作数栈 | 局部变量表 |
|---|---|---|---|
| 0 | `bipush 10` | `[10]` | `args` |
| 2 | `istore_1` | `[]` | `args, i=10` |
| 3 | `iload_1` | `[10]` | `args, i=10` |
| 4 | `istore_2` | `[]` | `args, i=10, j=10` |
| 5 | `return` | — | — |

### 后置自增 j++

`ReadClass03`：

```java
public class ReadClass03 {
    public static void main(String[] args) {
        int i = 10;
        int j = i;
        j++;
    }
}
```

`main` 字节码：

```text
0: bipush 10
2: istore_1
3: iload_1
4: istore_2
5: iinc 2, 1
8: return
```

| 偏移 | 指令 | 操作数栈 | 局部变量表 |
|---|---|---|---|
| 0 | `bipush 10` | `[10]` | `args` |
| 2 | `istore_1` | `[]` | `args, i=10` |
| 3 | `iload_1` | `[10]` | `args, i=10` |
| 4 | `istore_2` | `[]` | `args, i=10, j=10` |
| 5 | `iinc 2, 1` | `[]` | `args, i=10, j=11` |
| 8 | `return` | — | — |

### 前置自增 ++i

`ReadClass05`：

```java
public class ReadClass05 {
    public static void main(String[] args) {
        int i = 10;
        int j = ++i;
    }
}
```

`main` 字节码：

```text
0: bipush 10
2: istore_1
3: iinc 1, 1
6: iload_1
7: istore_2
8: return
```

| 偏移 | 指令 | 操作数栈 | 局部变量表 |
|---|---|---|---|
| 0 | `bipush 10` | `[10]` | `args` |
| 2 | `istore_1` | `[]` | `args, i=10` |
| 3 | `iinc 1, 1` | `[]` | `args, i=11` |
| 6 | `iload_1` | `[11]` | `args, i=11` |
| 7 | `istore_2` | `[]` | `args, i=11, j=11` |
| 8 | `return` | — | — |

`j++` 与 `++i` 的差异就在 `iinc` 与 `iload` 的先后：

| | `j++`（ReadClass03） | `++i`（ReadClass05） |
|---|---|---|
| 关键指令顺序 | `iload_1` → `istore_2` → `iinc 2, 1` | `iinc 1, 1` → `iload_1` → `istore_2` |
| 自增时机 | 取值之后自增 | 取值之前自增 |
