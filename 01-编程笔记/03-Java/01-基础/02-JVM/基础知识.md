# 基础知识

## 字节码解读

> [!note] 定义
> Java 中每个方法执行时，JVM 都会为它分配一块独立的内存空间，其中两块最重要：
> - `局部变量表`：存储方法的局部变量，按槽位编号（`0` 号通常是 `args`）
> - `操作数栈`：存储运算过程中参与运算的数据，遵循后进先出

> [!tip] 查看字节码
> 源码编译成 `.class` 后，用 `javap -c 类名.class` 反编译查看字节码指令。

涉及的核心指令：

| 指令 | 作用 |
|---|---|
| `bipush n` | 将字面量 `n` 压入操作数栈 |
| `istore_N` | 弹出操作数栈顶元素，存入局部变量表 `N` 号槽位 |
| `iload_N` | 将局部变量表 `N` 号槽位的数据复制压入操作数栈 |
| `iinc N, M` | 将局部变量表 `N` 号槽位的数据加 `M`（直接在槽位上操作，不经过操作数栈） |

下面四个示例从单步赋值递进到自增对照，源码如下：

```java
// 示例一：变量赋值 i = 10
public class ReadClass01 {
    public static void main(String[] args) {
        int i = 10;
    }
}

// 示例二：变量传递 j = i
public class ReadClass02 {
    public static void main(String[] args) {
        int i = 10;
        int j = i;
    }
}

// 示例三：后置自增 j++
public class ReadClass03 {
    public static void main(String[] args) {
        int i = 10;
        int j = i;
        j++;
    }
}

// 示例四：前置自增 ++i
public class ReadClass05 {
    public static void main(String[] args) {
        int i = 10;
        int j = ++i;
    }
}
```

四个示例 `main` 方法的字节码与逐条执行后的栈帧状态（`javap -c` 默认还会输出各例相同的默认构造方法 `aload_0` / `invokespecial` / `return`，此处省略）：

| 示例 | 偏移 | 指令 | 操作数栈 | 局部变量表 |
|---|---|---|---|---|
| ① `i=10` | 0 | `bipush 10` | `[10]` | `args` |
| ① | 2 | `istore_1` | `[]` | `args, i=10` |
| ① | 3 | `return` | — | — |
| ② `j=i` | 0 | `bipush 10` | `[10]` | `args` |
| ② | 2 | `istore_1` | `[]` | `args, i=10` |
| ② | 3 | `iload_1` | `[10]` | `args, i=10` |
| ② | 4 | `istore_2` | `[]` | `args, i=10, j=10` |
| ② | 5 | `return` | — | — |
| ③ `j++` | 0 | `bipush 10` | `[10]` | `args` |
| ③ | 2 | `istore_1` | `[]` | `args, i=10` |
| ③ | 3 | `iload_1` | `[10]` | `args, i=10` |
| ③ | 4 | `istore_2` | `[]` | `args, i=10, j=10` |
| ③ | 5 | `iinc 2, 1` | `[]` | `args, i=10, j=11` |
| ③ | 8 | `return` | — | — |
| ④ `++i` | 0 | `bipush 10` | `[10]` | `args` |
| ④ | 2 | `istore_1` | `[]` | `args, i=10` |
| ④ | 3 | `iinc 1, 1` | `[]` | `args, i=11` |
| ④ | 6 | `iload_1` | `[11]` | `args, i=11` |
| ④ | 7 | `istore_2` | `[]` | `args, i=11, j=11` |
| ④ | 8 | `return` | — | — |

`j++` 与 `++i` 的差异就在 `iinc` 与 `iload` 的先后：

| | `j++`（ReadClass03） | `++i`（ReadClass05） |
|---|---|---|
| 关键指令顺序 | `iload_1` → `istore_2` → `iinc 2, 1` | `iinc 1, 1` → `iload_1` → `istore_2` |
| 自增时机 | 取值之后自增 | 取值之前自增 |
