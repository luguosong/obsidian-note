# 电子印章基础知识

> 结构按 **GB/T 38540-2020《安全电子签章密码技术规范》（v4）** 整理，UOCS 平台主线版本。

## 电子印章 SESeal

### 数据结构

```
SESeal 电子印章
├── eSealInfo 印章信息 (SES_SealInfo)
│   ├── header 印章头 (SES_Header)
│   │   ├── ID            固定值 "ES"
│   │   ├── version       版本号（v4 取 4）
│   │   └── Vid           厂商 ID
│   ├── esID              电子印章标识（唯一编码）
│   ├── property 印章属性 (SES_ESPropertyInfo)
│   │   ├── type          印章类型
│   │   ├── name          印章名称
│   │   ├── certListType  证书列表类型（1=证书，2=证书杂凑值）
│   │   ├── certList      签章者证书列表 (SES_CertList)
│   │   ├── createDate    制作时间
│   │   ├── validStart    有效期起始
│   │   └── validEnd      有效期终止
│   ├── picture 印章图像 (SES_ESPictrueInfo)
│   │   ├── type          图像类型（GIF/BMP/JPG/PNG/SVG）
│   │   ├── data          图像数据
│   │   ├── width         显示宽度（mm）
│   │   └── height        显示高度（mm）
│   └── extDatas          自定义数据（OPTIONAL）
│       └── ExtData
│           ├── extnID    扩展字段标识
│           ├── critical  是否关键
│           └── extnValue 扩展字段值
├── cert                  制章者证书（X.509，DER）
├── signAlgID             签名算法标识
└── signedValue           制章者对 eSealInfo 的签名值
```

### 生成过程

电子印章由**制章者**（制章系统）生成，共三步：

1. **组装印章信息** `eSealInfo`
   将印章头（header）、印章标识（esID）、印章属性（property）、印章图像（picture）、自定义数据（extDatas）按 SEQUENCE 方式组成印章信息域。

2. **对印章信息签名** → `signedValue`
   按 `signAlgID`（SM2 + SM3），制章者用自身私钥对 `eSealInfo` 做数字签名，得到签名值。

3. **组包成印章** `SESeal`
   将 `eSealInfo`、制章者证书 `cert`、`signAlgID`、`signedValue` 组包，即得完整电子印章。

## 电子签章 SES_Signature

### 数据结构

```
SES_Signature 电子签章
├── toSign 待签章信息 (TBS_Sign)
│   ├── version           版本号（与印章 version 一致）
│   ├── eseal             所用电子印章 (SESeal)
│   ├── timeInfo          签章时间
│   ├── dataHash          原文杂凑值
│   ├── propertyInfo      原文属性
│   └── extDatas          自定义数据（OPTIONAL）
├── cert                  签章者证书（X.509，DER）
├── signatureAlgID        签名算法标识
├── signature             签章者对 toSign 的签名值
└── timeStamp [0]         时间戳（OPTIONAL）
```
