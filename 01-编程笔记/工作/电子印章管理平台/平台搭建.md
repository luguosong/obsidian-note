# 平台搭建

claude --resume d008b625-eb11-4992-926f-6f838d07db89

- 分为个人登录和企业登录，登录时进行身份认证 只能申请属于当前登录人的
- 印章申请 与 用章人 绑定 分离
- 自动化生成印章

## 平台应该有哪些角色

| 角色                | 描述                                                                              | 标准来源                                                                        |
| ----------------- | ------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| 制章者（R1）           | 具有制作和管理权限的机构；对印章信息域数字签名<br><br>核验材料、制作印文图像、录入系统、调用 CA 签发证书、生成 SESeal、备案、状态推送、交付 | GB/T 33481 §3.6 <br> GM/T 0047 §3.6 <br> GB/T 38540 §3.4 <br> C-0118 §9.3.1 |
| 签章者(R2)           | 印章所有者，具备法定使用权限的实体（`非自然人`）<br><br>保管载体与 PIN、发起用章申请/审批、用私钥对待签章数据签名                | GB/T 33481 §3.7 <br>GM/T 0047 §3.7 <br>C-0119 §7                            |
| 平台管理员 / 印章管理员(R3) | 系统级运维与权限管理；分散式下即签章操作人<br><br>系统/用户/权限/日志管理、分散式签章操作                              | C-0118 §9.2.3 a、§9.4.2.4 a                                                  |
| 操作员 / 申请人(R4)     | 发起制章或用章申请<br><br>录入申请信息并数字签名（或纸质签字）                                             | GB/T 33481 §5.2 + §6.3                                                      |
| 审批员 / 审核员(R5)     | 具审核权限、给审批意见<br><br>审核申请；用章审核还须核对印章有效性；记录结果并签名                                   | GB/T 33481 §5.2 + §6.3                                                      |
| 验章者 / 验证方(R6)     | 执行验章；标准未独立命名<br><br>本地验证 + 在线验证                                                 | GB/T 33481 §7 + 电子签名法 §34(2)                                                |
| 用章单位保管专人(R7)      | 保管密钥载体（USB-Key）的专人<br><br>参照实物用章保管载体、记录使用过程                                     | GB/T 33481 §6.2                                                             |

## 子系统

| 子系统                 | 部署       | 核心职责                               |
| ------------------- | -------- | ---------------------------------- |
| 信任支撑系统(S1)          | 国家平台     | CA 印章根证书、OCSP/CRL、唯一赋码、对接公安密码、全国互认 |
| 印章管理系统(S2)          | 国家平台     | 制作主体/制作系统/发布系统的注册与资料核验             |
| 印章制作系统(S3)          | 国家 + 地方  | 取印章根、取所有者证书、生成 SESeal、推送状态         |
| 状态发布系统(S4)          | 国家 + 地方  | 状态发布/查询/下载/变更；在线查询供验章、CRL 下载供本地验章  |
| 接入检测系统(S5)          | 国家平台     | 制作/发布系统接入前测试                       |
| 印章应用系统（签章/验章组件）(S6) | 使用主体自建   | 印章导入、签章、验章；集中式扩展用户/权限/日志审计         |
| CA（证书认证机构）(S7)      | 国家/第三方   | 签发系统证书 + 每枚印章的所有者证书                |
| USB-Key / 密码机(S8)   | 物理载体/服务端 | 分散式 SKF 接口；集中式服务端密码机               |
| 时间戳服务(S9)           | 可选       | 签章产生时间戳、验章验证（GB/T 20520）           |

## 监管角色

| 监管角色                   | 职责                     | 来源                        |
| ---------------------- | ---------------------- | ------------------------- |
| 电子印章制发部门(G1)           | 本地区/部门印章申请与注销管理        | 电子印章管理办法 §11/§13/§19      |
| 国家密码管理局 / 省级密码管理部门(G2) | 密码管理；监管电子政务电子认证服务机构    | §6/§10                    |
| 工业和信息化部(G3)            | 监管电子认证服务机构（CA）；设立审批、年检 | 电子签名法 §18/§19             |
| 国务院办公厅(G4)             | 推动全国一体化平台互信互认          | §7                        |
| 公安机关(G5)               | 依法打击涉印章违法犯罪（非备案审批主体）   | §9                        |
| 公安部印章系统(G6)            | 备案链路终点（GAData、下发对称密钥）  | C-0118 §9.2.1；C-0122 §6.1 |
