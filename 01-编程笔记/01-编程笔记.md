## 编程语言演进与时间线

![[Pasted image 20260901102438.png]]

|时间|语言|诞生初衷 / 主要解决的问题|最擅长领域|
|--:|---|---|---|
|1972|**C**|用高级语言替代大量汇编，同时保持接近硬件的性能和控制力|操作系统、驱动、嵌入式、底层库|
|1974|**SQL**|用声明式方式查询和操作关系型数据|数据库、数据查询、数据分析|
|1985|**C++**|在 C 的性能基础上增加面向对象和高级抽象能力|游戏引擎、CAD、浏览器、高性能系统|
|1991|**Python**|提高开发效率和代码可读性，让编程更简单|AI、数据科学、自动化、后端|
|1995|**Java**|解决跨平台和大型软件工程问题|企业后端、Android、大型业务系统|
|1995|**JavaScript**|让网页具有动态交互能力|Web 前端、Node.js、全栈开发|
|1995|**PHP**|简化动态网站和服务器端 Web 开发|Web 后端、网站、CMS|
|2000|**C#**|为 .NET 提供现代、安全、工程化的开发语言|企业后端、Windows、Unity|
|2009|**Go**|降低大型工程复杂度，提高编译、部署和并发开发效率|云原生、微服务、网络服务、CLI|
|2010|**Rust**|在保持 C/C++ 性能的同时解决内存安全和并发安全问题|系统编程、基础设施、WASM、高性能服务|
|2011|**Kotlin**|改善 Java 冗长、空指针等问题，同时兼容 JVM|Android、JVM 后端|
|2012|**TypeScript**|解决大型 JavaScript 项目缺乏静态类型、难维护的问题|大型前端、Node.js、全栈|
|2014|**Swift**|用更现代、安全的语言替代 Objective-C|iOS、macOS、Apple 生态|
