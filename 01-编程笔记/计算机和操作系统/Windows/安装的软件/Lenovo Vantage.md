# Lenovo Vantage

联想电脑自带的系统管理软件，类似于其他品牌的"控制中心"类工具。主要功能：

- **系统更新**：驱动、BIOS、系统补丁的检测与更新
- **硬件监控**：电池健康、温度、风扇转速
- **性能模式切换**：省电/均衡/性能模式，部分机型支持超频
- **快捷设置**：麦克风/摄像头隐私开关、护眼模式、电池保养模式（限制充电上限延长电池寿命）
- **保修查询**：设备序列号、保修状态查询
- **智能功能**（部分机型）：人体感应自动锁屏、防偷窥提示等

预装在联想笔记本上（ThinkPad、小新、拯救者等系列），可从微软商店单独安装。是可选工具，卸载不影响电脑正常使用，只是少了这些管理功能的图形界面（驱动更新等仍可通过官网或其他方式获取）。
