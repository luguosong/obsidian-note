# 字节码解读


> [!note] 定义
> Java 中每个方法执行时，JVM 都会为它分配一块独立的内存空间，其中两块最重要：
> - `局部变量表`：存储方法的局部变量，按槽位编号（`0` 号通常是 `args`）
> - `操作数栈`：存储运算过程中参与运算的数据，遵循后进先出

> [!tip] 查看字节码
> 源码编译成 `.class` 后，用 `javap -c 类名.class` 反编译查看字节码指令。

涉及的核心指令：

| 指令 | 作用 |
|---|---|
| `bipush n` | 将字面量 `n` 压入操作数栈 |
| `istore_N` | 弹出操作数栈顶元素，存入局部变量表 `N` 号槽位 |
| `iload_N` | 将局部变量表 `N` 号槽位的数据复制压入操作数栈 |
| `iinc N, M` | 将局部变量表 `N` 号槽位的数据加 `M`（直接在槽位上操作，不经过操作数栈） |
| `iadd` | 弹出操作数栈顶两个 `int`，相加后将结果压入操作数栈 |

把赋值、相加、后置自增、前置自增四步放进同一个 `main` 方法，一次性看全这些指令如何操纵栈帧：

```java
public class ReadClassDemo {
	// 在java语言中，任何一个方法执行时，都会专门为这个方法分配所属的内存空间。供这个方法使用。
	// 每个方法都有自己独立的内存空间。这个内存空间中有两块比较重要的内存空间：
	// 一块叫做：局部变量表
	// 另一块叫做：操作数栈
    public static void main(String[] args) {
        int i = 10;       // 示例一：变量赋值
        int j = i + 20;   // 示例二：变量相加
        j++;              // 示例三：后置自增
        int k = ++i;      // 示例四：前置自增
    }
}
```

执行过程中栈帧的变化「四个关键时刻，每步关键指令执行后的局部变量表 + 操作数栈」：

`javap -c ReadClassDemo.class` 输出的 `main` 方法字节码（构造方法各例相同，省略）：

```text
public static void main(java.lang.String[]);
  Code:
     0: bipush 10
     2: istore_1
     3: iload_1
     4: bipush 20
     6: iadd
     7: istore_2
     8: iinc 2, 1
    11: iinc 1, 1
    14: iload_1
    15: istore_3
    16: return
```

逐条指令执行后的栈帧状态（局部变量表槽位：`0=args`、`1=i`、`2=j`、`3=k`）：

| 指令          | 操作数栈       | 局部变量表                    | 说明                              |
| ----------- | ---------- | ------------------------ | ------------------------------- |
| `bipush 10` | `[10]`     | `args`                   | 将字面量 `10` 压入操作数栈                |
| `istore_1`  | `[]`       | `args, i=10`             | 弹出栈顶 `10`，存入 1 号槽位 `i`          |
| `iload_1`   | `[10]`     | `args, i=10`             | 把 `i` 的值 `10` 复制压入操作数栈          |
| `bipush 20` | `[10, 20]` | `args, i=10`             | 将字面量 `20` 压入操作数栈                |
| `iadd`      | `[30]`     | `args, i=10`             | 弹出栈顶两数 `10` 和 `20`，相加得 `30` 后压栈 |
| `istore_2`  | `[]`       | `args, i=10, j=30`       | 弹出栈顶 `30`，存入 2 号槽位 `j`          |
| `iinc 2, 1` | `[]`       | `args, i=10, j=31`       | 2 号槽位 `j` 直接加 `1`，不经过操作数栈       |
| `iinc 1, 1` | `[]`       | `args, i=11, j=31`       | 1 号槽位 `i` 直接加 `1`，不经过操作数栈       |
| `iload_1`   | `[11]`     | `args, i=11, j=31`       | 把 `i` 自增后的值 `11` 复制压入操作数栈       |
| `istore_3`  | `[]`       | `args, i=11, j=31, k=11` | 弹出栈顶 `11`，存入 3 号槽位 `k`          |
| `return`    | —          | —                        | 方法结束，栈帧销毁                       |

`j++` 与 `int k = ++i` 就在同一份字节码里，差别只在 `iinc` 与 `iload` 的先后：

| | `j++`（偏移 8） | `int k = ++i`（偏移 11-15） |
|---|---|---|
| 关键指令顺序 | `istore_2` → `iinc 2, 1` | `iinc 1, 1` → `iload_1` → `istore_3` |
| 自增时机 | 先赋值后自增（`j` 先得 30，再变 31） | 先自增后取值（`i` 先变 11，`k` 再得 11） |
