# Linux

Linux 是编程史上最著名的「业余项目变帝国」故事：一个大学生的 hobby 内核，如今运行着绝大多数服务器、全部 TOP500 超算与数十亿部 Android 手机。编年事件见 [[编程史]]。

## 一个帖子引发的帝国（1991）

赫尔辛基大学学生 Linus Torvalds 受 MINIX（Tanenbaum 1987 年发布的教学用类 Unix 系统，许可仅限教育用途）启发，1991 年 8 月 25 日在 comp.os.minix 发帖预告自写内核——他自称只是爱好、「不会像 GNU 那样大而专业」；9 月 17 日上传 0.01 版到 FTP（同事 Ari Lemmke 将目录命名为 Linux，他本人本想叫 Freax）。起步设备不过一台 Intel 386 PC。

## 许可证的抉择：GPLv2 与 GNU 合流（1992）

Linus 于 1992 年初将 Linux 从自订许可改为 GNU GPLv2：GNU 已备齐编译器与全套工具链、唯独内核 Hurd 迟迟未成，这个缺口恰被 Linux 补上，全球贡献者爆发式增长。内核至今坚持 GPLv2、未升级 GPLv3。

==许可证选择是 Linux 命运的分水岭==：许可开放的内核才能接住 GNU 社区与全球志愿者。

## 对手停摆送来的窗口期（1992–1994）

AT&T 旗下 USL 起诉 BSDi 使 BSD 系发布停摆约两年，大量用户转投初生的 Linux——技术之外的法律意外助攻（详见 [[BSD]]）。1994 年 3 月 Linux 1.0 发布（约 17.6 万行代码）已是功能完备的可用系统，同年 Red Hat 开启商业发行版时代。

## 发行版森林

- **Slackware**（1993）：现存最古老的发行版；
- **Debian**（1993）：社区驱动的典范，后世 Ubuntu 等众多发行版的上游；
- **Red Hat**（1994）：确立企业级 Linux 商业模式的代表；
- **Ubuntu**（2004）：以「Linux for Human Beings」定位免费寄送光盘、固定半年节奏，大幅拉低桌面门槛。

## 从追随者到统治者（1996 至今）

- **Linux 2.0**（1996）支持对称多处理，吉祥物企鹅 Tux 定名；
- **Linux 2.6**（2003）抢占式内核开启近八年长跑，奠定服务器与嵌入式领域的主导地位；
- **2017 年**起全球 TOP500 超级计算机全部运行 Linux；
- **2022 年**含 Android 在内的装机量登顶通用操作系统，前百万 Web 服务器约 96% 在其上；同年 Rust 并入内核，成为 C 之外第二种可编写内核的语言；
- **2026 年**主线跨入 7.x 时代。

它常被总结为设计未必最优、却赢在生态：开放协作 + copyleft 许可证让整个产业愿意站在它一边。
