# C语言

C 是系统编程的「拉丁语」：Unix 与其后绝大多数操作系统内核用它写成，C++、Java、C#、Go、Rust 的语法里都有它的影子。它诞生的动机只有一个——让操作系统摆脱特定硬件。编年事件见 [[编程史]]。

## 为移植 Unix 而生（1969–1973）

[[肯·汤普逊|Ken Thompson]] 先以 BCPL 为基础设计出 B 语言、用于早期 Unix；1969–1973 年间[[丹尼斯·里奇]]（Dennis Ritchie）在贝尔实验室为其补充类型系统等特性，演化为 C 语言——目的正是用高级语言重写 [[Unix]] 内核。1973 年 Version 4 完成：==操作系统第一次变得可移植==。

两者相互成就：C 让 Unix 走出贝尔实验室的 PDP 机型，Unix 又把 C 带遍各家硬件。

## 语言哲学：最小的核心，最大的自由

C 只保留极小的运行时与少数关键字，既贴近硬件获得接近汇编的效率，又提供结构化抽象能力——常被形容为「可移植的汇编」。代价是把内存管理等危险能力完全交给程序员，安全缺陷也成了延续至今的宿命话题。

## 标准化之路

Kernighan 与 [[丹尼斯·里奇|Ritchie]] 1978 年的《The C Programming Language》（K&R）是事实标准；此后 ANSI/ISO 标准相继迭代：C89/C90 → C99 → C11 → C17 → C23。

## 影响了谁

语法基因传给 C++、Objective-C、Java、C#、JavaScript、Go、Rust 等一长串后继者；操作系统内核、数据库、解释器等基础软件至今仍以 C 为主要载体。2022 年 Rust 进入 Linux 内核（详见 [[05-历史/编程史/Linux|Linux]]），意味着 C 的系统编程王座出现了第一个真正量级的挑战者。
