# Windows

Windows 是桌面计算半个世纪的默认名字。它的历史本质上是==两条产品线的并行与合流==：DOS 血统的消费线与 NT 血统的现代线，直到 XP 才真正合流。编年事件见 [[编程史]]。

## DOS 外壳时代（1985–1998）

- **Windows 1.0**（1985）：跳票两年的图形外壳，依附 MS-DOS、仅平铺窗口，最初反响平平；
- **Windows 3.0**（1990）：界面与性能大改，半年售出 200 万份，Windows 首次商业成功；3.1（1992）巩固地位；
- **Windows 95**（1995）：开始菜单与任务栏自此定型，支持 32 位应用；捆绑 IE 引爆浏览器战争，并为 1997 年 Sun 起诉微软（Visual J++ 与 [[05-历史/编程史/Java|Java]] 兼容性之争）埋下伏笔；
- **Windows 98**（1998）：深度集成 IE、原生 USB 支持；同年美国司法部反垄断诉讼立案。

## 另一条线：NT 内核的诞生（1988–1993）

前 DEC 工程师戴夫·卡特勒（Dave Cutler）1988 年底主持「NT OS/2」计划，1993 年 Windows NT 3.1 发布：32 位、抢占式多任务、与 DOS 无关的全新内核。当时它与消费线并行销售，日后却成为所有现代 Windows 的基座——==一条当时看似支线的项目，成了主线==。

## 合流与称霸（2000–2009）

- **两条线并行的最后一年**（2000）：NT 内核的 Windows 2000 面向企业与桌面，DOS 血统的 Windows ME 是绝唱（以不稳定著称）；
- **Windows XP**（2001）：NT 内核首次统一消费与商业市场，Luna 界面成一代经典，服役至 2014 年 4 月；
- **Windows Vista**（2007）：五年开发兼容性恶评如潮，但其安全架构为后续版本铺路；
- **Windows 7**（2009）：修正 Vista 的性能与兼容问题，口碑巅峰、长期份额第一。

## 服务化转型（2012 至今）

- **Windows 8**（2012）：磁贴「开始屏幕」赌触屏、移除开始菜单，桌面用户强烈反弹；
- **Windows 10**（2015）：转向「Windows 即服务」，免费升级、半年功能更新，自称「最后一版 Windows」；2025 年 10 月 14 日停止支持（可付费 ESU 延长），2026 年仍占近三成份额；
- **Windows 11**（2021）：圆角设计、任务栏居中、原生运行 Android 应用，2026 年 8 月约占七成桌面份额。
