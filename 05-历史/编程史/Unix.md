# Unix

Unix 是操作系统的「罗马」：类 Unix 血统覆盖了服务器、超算、macOS 与 Android 的几乎全部现代计算平台。它始于一次大型项目溃败后的自娱之作。编年事件见 [[编程史]]。

## Multics 的失败如何成就了 Unix？

[[肯·汤普逊]]（[[肯·汤普逊|Ken Thompson]]）等人退出庞大臃肿的 Multics 分时系统项目后，1969 年在贝尔实验室一台 PDP-7 小型机上用汇编写出雏形；1970 年 Brian Kernighan 以双关语 Unics 定名 Unix（1971 年发布第一版官方手册）。小工具各司其职、管道组合——与大系统针锋相对的设计哲学自此奠基。

## 可移植革命：用 C 语言重写内核（1973）

[[C语言]] 正是为移植 Unix 而生。1973 年[[丹尼斯·里奇]]等人用新生的 C 重写内核（Version 4），Unix 成为==第一个可移植的操作系统==，1977 年移植到 Interdata 机型、彻底摆脱 PDP 硬件绑定。软硬件就此解耦——这是 Unix 能统治其后四十年的关键一步。

## 自由传播与伯克利分支（1975–1983）

1975 年起源码以低廉费用授权高校（首份售予伊利诺伊大学），带源码的 Unix 在大学间迅速传播，伯克利的深度参与孕育出 BSD（详见 [[BSD]]）。1983 年 AT&T 发布面向商业授权的 System V，SunOS、HP-UX、AIX、Xenix 等商业衍生系统随之繁荣；开放火种由 BSD 延续。1988 年 IEEE 发布 POSIX 标准，统一类 Unix 的应用编程接口。

## Unix 战争：内斗的代价（1987–1993）

1987 年 Sun 与 AT&T 结盟开发统一 System V，IBM、DEC、HP 组建 OSF 对抗——阵营分裂、互不兼容拖累了 Unix 自身，给 Windows NT 崛起留下空间；1989 年 SVR4 尝试融合各方血统。战后商业 Unix 由 Solaris、HP-UX、AIX 主导，权利本身几度易主（1992 年售予 Novell，1993 年商标转入 X/Open）。

## 血统延续：谁继承了 Unix？

- **认证血脉**：苹果 1996 年收购 NeXT 后，基于 NeXTSTEP（Mach + BSD 混合的 XNU 内核）打造的 Mac OS X 于 2001 年发布，macOS 后来成为官方认证的 UNIX 系统；
- **开源再造**：[[05-历史/编程史/Linux|Linux]] 并非 Unix 代码后代，却完全继承其接口与生态（POSIX 兼容、GNU 工具链），规模上反超所有嫡系；
- **移动霸权**：iOS（与 macOS 同源）与 Android（Linux 内核）让类 Unix 统治了智能手机。
