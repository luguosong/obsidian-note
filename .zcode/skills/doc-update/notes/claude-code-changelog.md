# Claude Code 更新日志 — 更新方法

- 笔记：`网页裁剪/Claude Code 更新日志.md`
- 上游：https://raw.githubusercontent.com/anthropics/claude-code/refs/heads/main/CHANGELOG.md

本笔记是上游 CHANGELOG.md 的全量中文翻译，只做**增量翻译**：翻译本地尚未收录的版本段落，插入正文顶部；已翻译的旧版本段落一律不动。

## 步骤

1. **定位截止版本**：读笔记 `# 更新日志` 标题后的第一个 `## x.y.z` 版本标题，即已翻译的截止版本。这是权威依据——顶部维护说明 callout 里的「最新版本号」应与之一致，不一致时以正文为准并顺手改正 callout（callout 步骤示例中的旧版本号是历史示意，不理会）。→ 完成标准：拿到准确的截止版本号。

2. **拉取上游**：

   ```bash
   curl -sL "https://raw.githubusercontent.com/anthropics/claude-code/refs/heads/main/CHANGELOG.md" -o /tmp/cl_new.md
   ```

   → 完成标准：文件首行为 `## x.y.z` 版本标题（若拿到的是 404 提示页则判失败，报告并中止本篇）。

3. **截取增量**：取上游从第一个版本标题起、到截止版本标题（不含）为止的全部内容。上游版本号可能跳号（如 2.1.230 不存在），一律以「截止版本标题出现与否」为界，不做号段推断。若截止版本标题在上游找不到，改为逐版本与本地已有版本标题比对，仅取本地没有的版本。无增量时报告「已是最新（x.y.z）」，本篇结束。→ 完成标准：拿到待翻译原文，其中不含任何本地已有版本。

4. **翻译**：按 defuddle skill 的「学术翻译规范」（`.zcode/skills/defuddle/SKILL.md`）翻译，并遵守本笔记的既有约定：

   - 术语译法与笔记既有译文保持一致，拿不准时先 grep 笔记里该术语的既有译法。既有译法：智能体(agent)、子智能体、技能(skill)、钩子、词元(token)、自动模式、自动压缩、受管理设置、工作树、分叉、远程控制(Remote Control)、自托管、全屏、粘贴、跨会话、智能体视图；`marketplace` 保留英文。
   - 条目动词前缀照译：Added→新增、Fixed→修复、Improved→改进、Changed→更改、Removed→移除；无动词前缀的条目（如 `Remote Control:`、`Security:`、`Vim mode:`、`Windows:`）直译并保留冒号结构；`[VSCode]` 前缀保留英文并加粗为 **[VSCode]**。
   - 反引号内的命令、设置键、环境变量、路径、型号 ID 一律原样保留；版本标题 `## x.y.z` 不译。
   → 完成标准：增量全部译完，格式与既有版本段落一致（`## 版本号` + 无序列表）。

5. **插入**：将译文插入笔记 `# 更新日志` 标题之后、原第一个版本标题之前，保持段落间空行。→ 完成标准：新版本段落在最前，原有内容一字未动。

6. **标注发布日期**：为每个新增版本标题追加日期，格式 `## x.y.z（YYYY-MM-DD）`。上游 CHANGELOG 不带日期，唯一可靠来源是 npm registry 的发布时间，换算为北京时间（UTC 时间戳 +8 小时后取日期）：

   ```bash
   curl -sL "https://registry.npmjs.org/@anthropic-ai/claude-code" -o /tmp/cl_npm.json
   # 解析 JSON 的 time 字段：time["x.y.z"] 即该版本 UTC 发布时间
   ```

   个别版本已从 npm 下架（time 里查不到），取相邻两个已发布版本时间的中点估算，格式 `## x.y.z（约 YYYY-MM-DD）`。→ 完成标准：每个新增版本标题都带日期，且不早于其下方第一个（更旧的）版本的日期。

7. **刷新维护说明**：callout 中「最新版本号」改为上游最新版本号，「翻译时间」改为当天日期（`date +%F` 取）。→ 完成标准：callout 的版本号与正文首个版本标题一致。

## 验证

- `# 更新日志` 后第一个版本标题 == callout 最新版本号 == 上游最新版本。
- 插入点上下衔接处空行正确；全文无重复版本标题（对每个新版本号 `grep -c "^## <版本>"` 计数为 1）。
- 每个新增版本标题均带发布日期（精确或「约」前缀），日期顺序与版本顺序一致（越往下越早）。
- 抽查 1-2 条新译文：反引号内容未被翻译，术语与既有译文一致。
