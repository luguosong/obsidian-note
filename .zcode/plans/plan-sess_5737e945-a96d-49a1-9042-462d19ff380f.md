### 三、新建第 2 课：`lessons/0002-main-flow-in-action.html`（主流程实战）

用一个**虚构示例项目**（极简 todo CLI）端到端走一遍 idea→ship，每步讲"做什么、问什么、产出什么、如何衔接"：
1. **grill-with-docs**：展示会被追问的问题样例 + 产出的 `CONTEXT.md` glossary 片段 + 一个 ADR 例子。
2. **分支决策点**：一个问题需要 runnable 答案（如"这种状态模型对不对"）→ 绕进 prototype（用 handoff 双向桥接）。
3. **to-spec**：把对话综合成 spec（含 seams 讨论——优先用现有 seam、用最高 seam、理想只跨一个）；展示 spec 模板的关键段。
4. **to-tickets**：拆成 tracer-bullet 纵切片（每片 schema→API→UI→test 全打通、可独立验证、装得进一个新窗口）；讲 blocking edges；讲 **wide refactor 的 expand–contract 例外**。
5. **implement**：每个 ticket 开新会话；在 pre-agreed seams 驱动 tdd（红绿一片片）；收尾跑 code-review（**Standards + Spec 两个 parallel sub-agents**）再提交。
6. **Context hygiene**：1-3 步同一未打断窗口；每个 implement 全新窗口；逼近 smart zone（~120k token）还没到 to-tickets 就 handoff。
- 含 2 个练习：①一道纵切 vs 横切判断题；②一道 context hygiene 决策题（何时该 handoff）。
